# 铁计划

配置训练周期和成绩，生成力量举训练计划，逐组记录训练并查看肌群恢复和反馈。记录保存在应用的云端数据库。

创建或指定 SQLite 与 Git 实例，将它们的 ID 填入 source.json 的对应占位符，先执行 schema.sql，再运行 `npm ci` 和 `npm run build -- <完整提交号>`。安装素材由安装器放在应用文件目录的 `template-assets/` 下。保存冲突或连接失败时应用会提示，请保留未保存内容并重新打开。

在支持的浏览器中，离线入口准备完成后可通过“安装到桌面”使用。离线更改先留在本机，联网后返回应用同步到云端；如果云端已有更新，应用停止同步以保护两边数据，请保留本机数据。浏览器清理站点数据会删除尚未同步的离线更改。
