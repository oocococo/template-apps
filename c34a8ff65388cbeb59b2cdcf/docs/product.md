# 内容与数据说明

首屏由今日主焦点、完成数、任务清单、专注计时和近七天学习图表组成。首次打开时展示可一键加入的任务建议与明确的起步引导；任务、完成数与专注记录从用户实际操作开始累计。显示名称可修改并保存到 SQLite。用户新增任务后，它应立即出现在清单中，并在刷新后仍然存在。

侧边栏切换四个独立视图：今日总览把重点和下一步放在一起；学习任务可筛选全部、待完成和已完成，各筛选显示自身数量和对应任务，空结果给出相应提示；专注记录提供完整计时器、近七天时长和每轮记录；学习复盘展示七天图表、学习天数与累计完成任务。四个视图读取同一份 SQLite 数据，任务和计时状态在切换时保持一致。

`study_tasks` 存任务、领域、预估时间和完成时间；`study_sessions` 存完成的专注时段；`study_profile` 存显示名称。完成数由任务记录计算，七天图表由专注记录按日期汇总。清单与图表只读取当前 `workspace_id` 的记录。计时中途暂停或重置不算完成一次专注。

调整视觉时保留深蓝主焦点、浅色内容区、嫩绿行动按钮和明确的数字层级。数据较少时仍显示任务、可操作的专注计时和自然的鼓励文案；统计值应来自实际 SQLite 数据。
