# 周报工坊

按 ISO 周整理本周完成、进行中、风险与阻塞、下周计划。通过上一周、下一周、本周切换，历史抽屉按事项标题搜索并打开或删除周报。事项包含必填标题、项目标签、高中低优先级、非负耗时和备注；支持新增、行内编辑、取消、确认删除、上下移动及分区内拖动排序。本周完成可切换勾选与删除线；完成统计始终按分区条数计算。研发模板为 2/2/1/2 条，产品模板为 1/2/1/2 条，载入替换当前周。首次使用载入研发示例。

统计当前周总事项、本周完成分区条数、高优先级风险条数；本月完成为查看周周一所属公历月内所有周一的完成分区条数。Markdown 使用四个二级标题与项目/优先级/耗时/备注，飞书粘贴版使用四个方括号标题、编号列表及项目/耗时/备注。复制失败提供可选中文本。JSON 备份包含所有周，可导出并导入覆盖；导入前严格检查周键、四分区数组、事项字段及大小，失败不更改已有数据。

数据通过运行时连接持久化到应用绑定 SQLite，不依赖浏览器持久存储。应用内存缓存用于切换与搜索；每次写入原子保存周报归档，版本条件防止旧页面覆盖新数据。冲突或写入结果不明时停止编辑并提供重新读取，不自动重放写入。不同安装使用独立数据库。仅作个人周报使用，不含成员和共同编辑流程。

视觉采用青绿渐变顶部、浅灰背景、白色卡片：主色 #0d9488、渐变终点 #14b8a6、背景 #f6f8f8、文字 #1f2937、边框 #e5e7eb。系统中文无衬线字体；顶部标题 20px/700、周导航14px、区标题15px、事项14px、按钮13px。头部 sticky，内容最大1100px，内边距16px，卡片双列间距14px、圆角14px；统计四列、圆角12px；860px以下卡片单列、统计两列。历史入口左侧竖排、右抽屉320px/最大88vw，滑入250ms；按钮与事项150ms；底部toast淡入滑入300ms、2200ms消失。删除使用页面内确认框。手机保留相同入口与顺序，表单自动换行。

验收：四区 CRUD/排序/勾选及统计、两套模板替换、跨周与历史搜索、删除取消、空标题与无效JSON、两种文本复制、JSON下载上传、数据库写入后刷新及重新打开、桌面手机核心流程、图标、两种安装隔离与源码干净构建。预览使用相同结构样式及页面内合成数据，提示仅本页保留并可重置；下载入口注明安装后可用。
