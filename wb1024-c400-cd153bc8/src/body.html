何以中国

五千年不是一个整齐的数字，而是一条反复断裂又反复接续的河流。它的独特之处在于：文字未绝、典籍未绝、制度的精神未绝。

唯一未断的古老文明

与古埃及、两河流域、古印度并称四大文明古国，唯有中华文明的文字系统从甲骨文一路演进至今。今天的孩童仍能读懂两千年前的「学而时习之」，这是文明连续性的直接证据。

治乱循环中的制度演进

从西周的宗法分封，到秦的郡县官僚；从汉的察举，到隋唐的科举；从唐的两税法，到明的一条鞭法、清的摊丁入亩——每一次大乱之后，税制与选官制度都被重新锻造一次。

农耕帝国的技术底色

精耕细作、水利工程、铁犁牛耕支撑了庞大人口；造纸、印刷、火药、指南针经由丝绸之路与海上航路传向世界，深刻改写了全球历史的走向。

多元一体的格局

中原农耕、草原游牧、绿洲商贸、山地渔猎长期互动。辽、金、西夏、元、清等政权并非「外来的插曲」，而是共同塑造了今日中国疆域与族群结构的内在组成部分。

究天人之际，通古今之变，成一家之言。
—— 司马迁《报任安书》

地理

疆域不是一条画好的线，而是农耕与游牧反复推挤的结果。本栏把每个时期拆成五个维度：面积估算、四至方位、邻接政权、都城迁徙、州郡沿革——共二十三个时期、七十五处都城。

数据来源谭其骧主编《中国历史地图集》；周振鹤《中国地方行政制度史》；邹逸麟《中国历史地理概述》；各断代史地理志
呈现方式面积条形对比（点击切换朝代）+ 四至方位图 + 邻接政权 + 都城迁徙链 + 沿革条目；面积取学界通行估算口径，非精确测量
边界说明本栏不绘制任何地理边界线。历史疆界与现代国界含义不同，以面积与文字四至呈现，可避免误读；现行标准地图请以自然资源部标准地图服务为准

文物

每朝三到五件代表作，共 97 件。文物是史书之外的第二种证据：它不解释，也不说谎。按材质与形态筛选，点击名称看详情。

数据来源中国国家博物馆、故宫博物院、上海博物馆、湖南博物院、湖北省博物馆、甘肃省博物馆等馆藏著录；《中国文物精华大辞典》；各遗址考古发掘报告
呈现方式按朝代分组的卡片墙，卡片标注类别、年代、材质与收藏地；原件失传或仅存摹本者已在年代与说明中注明

世界坐标

同一时刻，别处也在发生历史。共 94 件同期世界大事，每条都附「同期中国」锚点与一句横向对照——罗马、波斯、伊斯兰黄金时代，都在这条线上。

数据来源《剑桥古代史》《剑桥中世纪史》《新编剑桥世界近代史》；斯塔夫里阿诺斯《全球通史》；吴于廑、齐世荣主编《世界史》；中国各史《西域传》《大食传》等

成语典故

成语是历史的压缩包。共 115 条，按朝代归类，标注最早可考出处——语本与定型分开写，小说戏曲不作唯一依据。

数据来源《汉语成语大词典》（中华书局）；《辞源》；所引典籍原文（《左传》《史记》《汉书》《晋书》《宋史》等）
呈现方式按朝代分组的词条卡：词形 + 类型（成语/典故/熟语/名句）+ 出处 + 今义 + 本事；类型可筛选，词形与出处可检索

结构一致

所有内容模块都是「对象 + 朝代 id 键」的形式，键名与 DYNASTIES.id 严格对应；单条记录的字段固定，不因朝代特殊而变形。校验脚本可直接比对缺漏。

便于扩展

新增朝代：在 data.js 加一条，再在 lore / media / geo / relics / world / idioms 各补一条同名键。新增栏目：在 app.js 的 ITEM_KINDS 与 GENERIC 各登记一行，对照台即自动支持。

年代口径

上古年代为约数，采用夏商周断代工程与学界通行说法；公元前后用「前 / 后」区分。面积、兵力等数字均为估算，页面已逐处标注口径，不作精确断言。

虚构与史实

神话、影视、成语的「本事」与史实分置呈现，各自标注出处与性质。凡属传说、摹本、存疑者，均在条目内明示，不以文学叙事替代史料。
