# 不忙：产品说明

## 定位

个人待办与日程。事项先按重要、紧急放进四象限，再在时间轴上拖到具体时段。功能保持少而直接：没有项目、标签、提醒或重复规则。

## 事项

| 字段 | 说明 |
| --- | --- |
| 标题 | 必填，最多 200 字 |
| 重要 / 紧急 | 决定所在象限 |
| 日期 | 可空。空表示「还没想好哪天」 |
| 开始时间、时长 | 有日期才能定时间；时长 15 分钟到 24 小时，不跨午夜 |
| 备注 | 可选，最多 2000 字 |
| 完成 | 记录完成时间；可撤销 |

## 四象限

- 只列未完成事项；「显示已完成」附加每象限最近 20 条已完成的（本次加载范围内）。
- 卡片排序：有日期的按日期和时间在前，未定日期的按创建时间在后。日期早于今天显示为逾期色。
- 拖动卡片到其他象限修改重要/紧急，提示可撤销。点卡片编辑，点圆圈完成。

## 时间轴

- 日期条一次显示一周（周一开始），圆点表示当天未完成事项的象限。左右箭头翻周，「今天」回到今天。选中日期写入地址 `#/timeline/YYYY-MM-DD`，刷新后保留。
- 待安排：未完成、没有开始时间，且日期为空、等于所选日、或（所选日是今天时）早于今天。按象限顺序排列。
- 时间轴：已定时的事项按开始时间与时长定位，重叠时并排。今天显示当前时间线。打开时滚到当前时间附近或当天第一件事。
- 拖动：托盘事项拖入时间轴定时；时间轴事项上下拖改时间、拖回托盘取消时间、拖到日期条换日期（保留时间）；拉底边改时长。均按 15 分钟对齐。
- 点空白时段以该半点为开始时间新建。

## 加载

打开时读取全部未完成事项；已完成事项按所看周读取。每次写入按事项排队，避免先后颠倒。
