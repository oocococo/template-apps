# 拾账的内容与数据

## 使用与冷启动

个人收支账本包含收支明细和分类统计两个哈希视图。初次进入的收入、支出和结余均为零；常用分类只预选表单，用户保存才产生记录。金额可单独填写，未填名称时使用分类名。保留清透蓝色、分层收支区、快捷分类与自定义下拉菜单。

## 存储与查询

`ledger_entries` 存每条账单，`(app_id, id)` 主键供定点编辑、删除及不确定结果核实；`(app_id, date, id)` 索引供所选月份的范围读取。同库复用时以清单 `web_id` 作为查询范围。金额存整数 `cents`，显示为人民币元；月度支出、收入、结余与分类比例由所选月份的实际记录计算，不另存统计状态。

快速连点保存只提交一次。保存失败保留表单；下次用户保存前先读取原记录 ID 核实，再提交当前修改。删除只作用于用户选定记录。
