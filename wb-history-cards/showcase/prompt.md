# wb-history-cards

制作个人历史策略卡牌：15剧本、21英雄与特性、局势迷雾和伪装妄念，11种手牌、行动额度、实力连接和天时乘数、摊牌受挫与特殊剧本胜负，保存/继续个人对局及战绩。保留合法目标和数值边界。

执行 `tiana web init-template wb-history-cards --dir my-app --json` 拉取完整源码。按 metadata.json 为新应用替换SQLite和Git实例变量，先执行schema.sql，再构建并配置固定入口。使用Tiana运行时的动态账号鉴权和参数化SQL，保留个人数据记录与响应式界面；按自己的偏好修改默认内容、配色和排版。
