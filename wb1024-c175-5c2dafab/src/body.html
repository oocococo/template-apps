    C4DCINEMA 4D

    C4D 需要先导出

    project.c4dCINEMA 4D PROJECT

    Cinema 4D 的 .c4d 是 Maxon 的封闭二进制工程格式，浏览器端没有公开解析器，无法像 FBX / GLB 那样直接读取。请从 Cinema 4D 导出为 FBX 或 GLB 后再载入。

    1. 在 Cinema 4D 中打开工程确认模型、材质和贴图都已正确显示。
    2. 导出 FBX「文件 → 导出 → FBX」，推荐 Binary 2020 / 2014，并勾选 Embed Textures / 嵌入纹理。
    3. 或导出 GLB / glTF如果当前 C4D 版本支持 glTF，导出时同样选择嵌入贴图。
    4. 拖入导出的文件把 FBX / GLB 和外部贴图文件夹一起拖入 FORMA；也可以先拖入 FBX，再补充贴图文件夹。

    动画项目请在 FBX 导出中启用 Bake Animation / 烘焙动画。压缩包里的 .c4d 不会被修改，FORMA 也不会读取或上传它。
