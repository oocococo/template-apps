# 健身管理产品规格

面向健身场馆的订单、客户、招生官、门店与提成管理。使用平台身份访问，获授权者共享同一应用的数据；不同安装的数据彼此独立。

首页展示实际提成、今日订单与营收、新客户、待结算提醒、快捷入口、近七日看板、招生官排行和最近订单。底部导航依次为首页、订单、客户、提成、报表、招生官。各业务列表提供搜索与筛选，详情提供编辑；删除须确认，删除客户不删除关联订单，删除招生官清空订单和客户归属。

订单记录客户、电话、课程、门店、费用、优惠、到款、招生官、支付及跟进资料。提成可按比例或固定金额；支持本单单独费率及二级推荐金额。按比例主提成为报名费用减优惠后乘生效费率并四舍五入；固定金额取整。实得为主提成减二级金额，最低为零。二级分成不单独结算。待付款订单可设置是否计入统计，但保留在明细。结算可标记状态并记录时间。报表按时间和招生官展示明细与汇总。

客户记录姓名、电话、标签、课程、门店及招生官，展示关联订单。招生官记录联系方式、类型及可选收款信息，改名同步归属。门店记录名称、地址、电话与营业状态。课程记录默认价格与费率。订单支持 CSV 导入，以电话去重并反馈结果；支持表格、提成明细与打印文档导出，JSON 备份和确认覆盖恢复。

桌面在淡紫色背景中央显示手机外壳，393×852，深色边框 10px、圆角 44px；宽度不超过 430px 或高度不超过 880px 时全屏。主色 #7D3BED、深紫 #6E29D9、浅紫 #F5F2FF，使用系统中文无衬线字体、白色卡片和 78px 固定底部导航。保留各页面信息顺序、控件状态及操作步骤。按钮按下有缩放，图表切换使用约 0.4 秒过渡，确认与选择面板从底部滑入，遮罩渐显。

验收覆盖上述核心流程与异常输入、文件导入导出和备份恢复，以及刷新和重开后的持久化；两位获授权用户须在同一应用中验证读写和冲突提示。桌面与手机分别检查交互、布局、视觉状态和动效。记录更新使用版本检查；批量结算、关联重命名和备份恢复在数据库内作为原子操作。密码备份使用 PBKDF2 与 AES-GCM，无密码备份为 JSON。
