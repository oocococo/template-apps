调用入口目录

国内平台

      
不需要代理、走人民币账单、数据留在境内。做产品上线或政企项目，优先从这里选。

      

    

    

      
海外平台

      
模型选型最全、迭代最快。OpenRouter 适合做多模型对比与回退，Ollama / vLLM 适合把开源权重拿到本地。

      

    


    
    

      
上手教程

      
三条最常见的落地路径。每条都能在十分钟内跑通第一段代码。


      

        
        
        
      


      

        

          

            

              
选平台、拿一个 key

              
国内推荐硅基流动（多家模型一个 key）、智谱 BigModel（GLM 有免费额度）；海外推荐 OpenRouter（一家通吃）。注册后在控制台创建 API Key。

            

            

              
装 SDK，改 base_url

              
所有平台都兼容 OpenAI 的调用格式，只需要把 base_url 和 model 名换掉，业务代码一行不用动。

              
# 国内（硅基流动）
from openai import OpenAI
client = OpenAI(api_key="YOUR_KEY", base_url="https://api.siliconflow.cn/v1")

# 海外（OpenRouter）
# base_url="https://openrouter.ai/api/v1"

r = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-V3.2",   # 以控制台模型名为准
    messages=[{"role": "user", "content": "帮我写个 LRU 缓存"}]
)
print(r.choices[0].message.content)

            

            

              
加一层可切换的封装

              
把「平台 + 模型名」读环境变量，方便按任务切模型。生产环境建议在网关层做限流与回退。

              
MODEL = os.getenv("MODEL", "deepseek-ai/DeepSeek-V3.2")
BASE  = os.getenv("BASE_URL", "https://api.siliconflow.cn/v1")

            

          

        

      


      

        

          

            

              
先看显存够不够

              
粗略的显存需求：参数量 × 每参数字节数。4bit 量化约 0.55 字节/参数，8bit 约 1 字节，FP16 约 2 字节。

              例：8B 模型 4bit ≈ 5G 显存；14B 4bit ≈ 9G；32B 4bit ≈ 20G；70B 4bit ≈ 40G（需双卡或量化更狠）。

            

            

              
用 Ollama 一条命令跑起来

              
适合试玩、离线场景，装完即用，自动挑量化版本。

              
ollama run qwen3:4b        # 笔记本 / 集显也够
ollama run gpt-oss:20b     # 约 16G 显存
# 本地 OpenAI 兼容端点：http://localhost:11434/v1

            

            

              
要吞吐就上 vLLM

              
团队自建服务的事实标准，支持张量并行，把大模型拆到多张卡上。

              
pip install vllm
vllm serve Qwen/Qwen3-Coder-480B-A35B-Instruct \
  --tensor-parallel-size 4 --max-model-len 65536 --port 8000

            

            

              
权重从哪下

              
国内优先魔搭（速度快、有国内镜像），海外用 Hugging Face。同一个开源模型两边通常都有。

              
pip install modelscope
python -c "from modelscope import snapshot_download;
snapshot_download('Qwen/Qwen3-4B-Instruct')"

            

          

        

      


      

        

          

            

              
为什么能接 —— 协议兼容

              
多数 Coding Agent（Claude Code 类工具）支持通过环境变量改 base_url 与鉴权 token，只要平台提供 Anthropic 兼容或 OpenAI 兼容协议即可。

            

            

              
国内不出境的一条路

              
智谱 BigModel 提供 Anthropic 兼容端点，直接给终端工具用。

              
export ANTHROPIC_BASE_URL="https://open.bigmodel.cn/api/anthropic"
export ANTHROPIC_AUTH_TOKEN="YOUR_KEY"
claude

            

            

              
海外 / 多模型切换

              
用 OpenRouter 的 key 做统一入口，模型名换成 qwen/qwen3-coder、deepseek/deepseek-chat 即可在同一条链路里换模型。

              
export OPENAI_BASE_URL="https://openrouter.ai/api/v1"
export OPENAI_API_KEY="sk-or-v1-..."

            

            

              
成本控制小技巧

              
给小任务配便宜模型（4B / 20B 量级），把复杂重构留给旗舰模型，用路由层按任务分流，账单通常能降一个数量级。
