提前还贷决策助手 · 通用测算计算器

一个工具算清「该不该提前还贷、还多少、选哪种方式」。支持等额本息 / 等额本金，覆盖公积金贷 / 商贷 / 组合贷等，并纳入首套个税利息抵扣的真实收益测算。①→③ 设置参数，第 ④ 部分出结论。纯本地运算、无后端、即开即用。
🤔 提前还贷，你是不是也纠结过这几个问题？
  • 「等额本息前期利息太多，提前还了是不是亏？」——前几期利息是沉没成本，真正该算的是未来。
  • 「提前还款，选'减少月供'还是'缩短期限'？」——同样的钱，两种选法累计利息能差一倍。
  • 「首套房能抵税，提前还了税盾没了，到底划不划算？」——要把抵税算进净收益才看得清。
本工具把这套「高频、高金额、高焦虑」的还贷决策，变成「填几个数 → 看一张对照表」。

规则：贷款利率 > 存款利率 → 提前还款"赚"（保留现金的机会成本高于还贷省下的利息）；反之则"亏"，保留现金更划算。只要存款率低于贷款利率，提前还款即稳赚；不存在"还到某个数最划算"的内点，闲钱越早还越值。
若启用「首套房贷利息抵扣」：抵税相当于降低贷款实际融资成本，提前还款会损失未来的税盾，因此"收益最大化"需把抵税纳入净收益测算（见第 ④ 部分）。边际税率无需手填——填写「年应纳税所得额」后，工具自动按个税 7 级累进税率表匹配所属税档并精确计算税盾（已考虑跨档）。

关于本作品

本作品为 WorkBuddy「1024 造物挑战」程序员节应用创作大赛 参赛作品。核心是一个零依赖、纯前端的「提前还贷决策助手」：输入贷款参数与你的闲钱，即可对比「一次性提前还 / 每月额外还 / 每年额外还」三种方式，并在「减少月供」与「缩短期限」之间给出量化结论，纳首套抵税后的真实净收益。

技术栈：单文件 HTML + 原生 JavaScript，计算引擎纯函数化（monthlyPayment / totalInterest / scenarioKeepTerm / scenarioShortenTerm / simulateExtra），无后端、无第三方依赖、数据不出本地。新增还款方式只需扩展纯函数，渲染层无需改动。
