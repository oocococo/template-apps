🧠 装机兵器谱 · 科普文章实战技巧汇编

从装机过程中各类科普文章提炼的可复用方法论。不是知识点堆砌，是「下次买硬件还能用」的判断框架。每条技巧附「落地做法」参考。

📖 识货篇 · 看穿营销话术
技巧 01

芯片规格拆穿术

型号数字 ≠ 性能等级。买显卡先查四张底牌：

  • 芯片代号（Navi 44 / GB206）→ 真实定位
  • CU / SP 数 → 算力规模
  • 显存位宽（128/256-bit）→ 带宽天花板
  • PCIe 通道（x8 / x16）→ 老板瓶颈
落地做法：9060 XT = Navi 44 / 32CU / 128-bit / PCIe 5.0 x16 满通道——文章 x8 警告对 128-bit 卡无效——1080p 下被 32MB Infinity Cache 盖住
技巧 02

Infinity Cache 原理

用大缓存补窄位宽，命中率随分辨率升高而下降：

  • 1080p：命中率极高，128-bit 短板几乎消失
  • 2K：命中率下降，带宽瓶颈开始显现
  • 4K：缓存形同虚设，靠纯位宽硬扛
  • 公式：显存带宽 = 频率 × 位宽 ÷ 8
落地做法：1080p 240Hz 场景正好把 128-bit 中端卡的短板最小化；换 2K 屏则 1% Low 会跌
技巧 03

HDR 真假辨别术

标注 HDR ≠ 有 HDR 效果，看三个硬指标：

  • 亮度 ≥ 600 nits（400 = 凑数）
  • 分区背光 / Mini-LED / OLED（无分区 = 暗部亮不起也暗不下）
  • VESA DisplayHDR 认证（无认证 = 厂商自标）
  • 原生 8-bit 面板开 HDR 会有色彩断层
落地做法：二手/入门高刷屏常见 400nits + 无分区 + 无 VESA 认证 = HDR 凑数功能，日常保持 SDR 不开
技巧 04

磁轴扫盲

机械轴 ≠ 磁轴，认准三件事别被参数带节奏：

  • 核心卖点 = RT 快触发 + 可调触发距离：霍尔传感器无物理触点磨损，触发点 0.1mm-4mm 自定义，FPS 急停/微调靠它，传统红轴没有
  • 8KHz / 0.6ms / 一键 4 功能 = 营销噱头：1K 与 8K 人眼不可分辨；按键绑定 4 指令是给宏玩家用的，普通人用不到还易误触
  • 磁轴打字手感偏硬：触底靠橡胶垫，比 Cherry MX 硬，长时间打字易累；纯办公/3A 玩家买传统红轴更舒服
选购提示：键盘和鼠标可按游戏需求、手感、连接方式与预算选择。

FPS 耳机选型术（玩家意见）

五轴速记法（青红茶黑银）

选轴别背参数，记住两个关键词：有没有段落感 + 按起来重不重，五种轴一眼看穿：

  • 青轴：段落感强 + 最响（咔哒声）→ 打字爽感拉满但吵，宿舍/办公室劝退

  • 黑轴：线性 + 重 → 大力士，误触率低但费手指，打字累，买的人少了
  • 银轴：线性 + 极短行程（碰一下触发）→ 为竞技而生，但打字易误触
  • 真言：看再多文章不如几十块试轴器按一遍

QLC vs TLC 定价拆穿

QLC 卖得比 TLC 还贵？先分容量档再看寿命，别被单档价格带节奏：

  • 看寿命（TBW）：QLC 颗粒寿命天然比 TLC 短一截——同容量 TBW 对半砍是常态，性能跑分再猛也补不回颗粒本质
  • 看容量档：1TB 是「价格锚点档」最容易虚高；2TB/4TB 才是 QLC 的真实性价比区间（每 GB 单价更划算）
  • 看缓外速度：SLC Cache 耗尽后 QLC 直写速度断崖，宣传的 7400MB/s 是爆发值不是持续值
  • 看市场背景：2026 存储涨价周期下（呼应第二十六/三十节），「新盘贵」≠「厂商收割」，先对比自家老款现价和竞品同档
落地做法：致态 Ti600s（4.0 QLC）1TB ¥1189 vs 三星 990 PRO（4.0 TLC 旗舰）1TB ¥1099——QLC 比 TLC 旗舰还贵 ¥90，1TB 档确实离谱；但 2TB 档 Ti600s ¥1889 vs 990 PRO ¥2899（省 ¥1010）反而合理。且 Ti600s 相对上代 Ti600 现价只贵 ¥90——贵的是整个市场（Ti600 2023 首发 1TB ¥299 → 现在 ¥1189，涨 4 倍）。结论：1TB 别买，2TB 才符合 QLC 性价比定位。旧盘复用 + 未来扩容 M.2 槽时参考

技巧 24

CPU 接口速查（1700 / 1851 / AM4 / AM5）

装机第一步先对接口：接口不对，物理上就插不进去，后面全白搭。速查 + 三个坑：

  • Intel（LGA 触点式，针脚在主板上）：1700 = 12/13/14 代 + 600/700 系，DDR4 或 DDR5（看板子），在售性价比主流；1851 = Core Ultra 200 系 + 800 系，仅 DDR5，升级路径可能只一代
  • AMD（AM4 为 PGA 针脚式，AM5 为 LGA 触点式）：AM5 = Ryzen 7000/8000/9000 + 600/800 系，仅 DDR5，官方承诺支持到 2027+；AM4 = Ryzen 1000~5000 + 300/400/500 系，仅 DDR4，预算装机/二手首选
  • 坑一 BIOS：接口对上但 BIOS 太老可能点不亮（如 B450 插 Ryzen 5000 需先刷 BIOS）——买前上官网查 CPU 兼容列表
  • 坑二 内存类型：1700 板分 D4/D5 版、1851 仅 D5、AM4 仅 D4、AM5 仅 D5——别买了 DDR5 内存发现板子是 DDR4 槽
  • 坑三 散热扣具：Intel 1700/1851 孔位相同可通用；AM4/AM5 扣具不同，AM4 散热器上 AM5 需换扣具套件（多数厂家免费送）
选择 CPU 和主板时核对插槽、芯片组、BIOS、内存类型及散热器扣具；更换内存类型的平台时应计入内存成本。

技巧 28

即插即用真相：基础功能免驱，RGB/宏需装厂软

「即插即用（PnP）」= 物理插入 + 软件自动配置，系统后台干了三件事：

  • 自动识别：读设备内固化的描述符（厂商 ID / 产品 ID / 类型），知道插进来的是鼠标还是显卡
  • 自动分配资源：系统查空闲的中断（IRQ）/ I/O 端口 / 内存地址并指派，防止硬件冲突
  • 驱动匹配：从系统驱动库或联网装好驱动，设备才能用
  • 历史坑：早期 ISA 总线无此能力，需手动跳线设 IRQ/DMA/IO；两卡同 IRQ 就「IRQ 冲突」死机。PCI/USB 出现后 PnP 才成熟，早年甚至被嘲「Plug and Pray（插上祈祷）」
参考提示：即插即用通常只保证外设基本功能；灯效、宏键等附加功能可能需要安装相应厂商的软件。
技巧 29

主板三看：尺寸 / 阵营 / 芯片组，B760M 是闭眼入之选

选主板就三个维度，顺序不能乱：

  • 看尺寸（版型）：E-ATX(305×330) > ATX(305×244) > M-ATX(244×244) > Mini-ITX(170×170)；尺寸决定机箱大小与扩展槽数量，越小越省空间但槽越少、集成散热要求越高
  • 看阵营（接口）：Intel 板只插 Intel、AMD 板只插 AMD，接口互不通用（LGA1700 vs AM5）；CPU 与主板必须一一对应
  • 看芯片组（级别）：Intel H 入门(不超频) / B 主流(闭眼入) / Z 高端(支持 K 超频)；AMD A 入门 / B 主流 / X 高端
  • 新手公式：M-ATX + B 系 = 性价比最高、最不容易出错；不想折腾超频就闭眼入
选购提示：选主板时先核对板型、CPU 插槽、芯片组、内存类型与插槽数量；带无线功能的型号还需安装天线并配置驱动。

星闪 NearLink：华为献技、国家牵头，下一代短距无线但当前外设别等

短距离无线通信的「 next-gen 」方向，文章叙事大体对、但几处被戏剧化：

  • 起源属实：2019 华为被移出蓝牙/WiFi 联盟会员序列 → 自研「超级蓝牙（绿牙）」→ 阉割演进为星闪；2020 星闪联盟成立（工信部指导、华为 + 国内厂商共建，类似「书同文车同轨」统一标准）
  • 技术核心属实：SLB 高速模式用 polar 码（土耳其 Erdal Arıkan 2008 提出、华为重金投入），延迟宣称低至 20µs、距离 / 抗干扰 / 功耗全面优于蓝牙
  • 偏差提示（文章过度渲染）：①「绝对上位替代蓝牙」过早——星闪与蓝牙长期共存、生态早期；②「核心优势全来自 polar 码」简化——低延迟是 PHY/MAC 整体设计；③「蓝牙联盟怕掀桌恢复资格」戏剧化，实际标准开放、华为本就能用蓝牙技术；④ 自动驾驶联动是展望非既成事实
  • 兼容性提示：无线音频协议通常需要耳机和手机两端支持；具体型号与连接方式以厂商资料为准。
参考提示：耳机和输入设备应核对蓝牙、2.4G 或其他无线协议的兼容性；两端协议不同时可能需要使用共同支持的连接方式。

内存双通道插法：DDR4 后插 2、4；2 槽板插满即双通道

2026-08-21 科普文章「一根内存插哪个？两根怎么组双通道？」——4 槽主板通道分配与插法：

  • 双通道原理：CPU 同时走两条内存通道、带宽≈翻倍；插错=两条内存挤同一通道，另一条空转，性能白白浪费（核显用户帧数差最明显）
  • 4 槽板通道分配：双通道需要分别使用两个内存通道；四槽主板常推荐优先使用 A2 和 B2，但槽位顺序和命名因型号而异，应以主板手册为准。
  • 安装位置：按主板手册确认 A2、B2 等槽位的实际位置，再插入对应内存通道。
  • 别信颜色：老板靠同色槽区分，新板（B650 / Z790）全黑无颜色；最靠谱看说明书「Installing Memory」页或主板丝印 DDR4_A1/A2/B1/B2——保证一根 A 一根 B 即可
  • 插错不烧机：最多双通道没生效、带宽没跑满，系统照进；少数板 BIOS 弹「未装推荐槽」提示但不影响进系统；CPU-Z 看 Channels# = Dual 即成功
  • 误区：① 不同品牌 / 型号也能组双通道（同为 DDR4 / DDR5 即可，以慢者参数为准）；② 双通道是带宽翻倍非频率相加
参考提示：双通道配置应按主板说明书选择内存插槽；安装后可用系统工具检查容量和通道状态。

  • 清灰节奏：半年到一年清一次；机箱/CPU 风扇 3-5 年油封干了变「拖拉机」，换扇不贵，但放任会加速全盘老化

AMD 对标 DLSS 4.5 的是 FSR Redstone：四件套补齐，唯独缺多帧生成

参考：NVIDIA、AMD 与相关技术评测对 DLSS 4.5 和 FSR 的介绍。

  • 命名先理清：AMD 没有「FSR 4.5」这个专名。原 FSR 4 在 2026 年 3 月正式改名为 FSR Upscaling，并和帧生成 / 光线再生 / 辐射缓存打包成一个套件叫 FSR Redstone——这才是真正对标 DLSS 4.5 的东西
  • FSR Redstone 四件套：① FSR Upscaling（ML 超分，原 FSR 4）② FSR Frame Generation（帧生成）③ FSR Ray Regeneration（光线再生，对标 DLSS Ray Reconstruction）④ FSR Radiance Caching（辐射缓存 / 实时全局光，DLSS 无直接对应项）
  • 超分画质已逼近：FSR Upscaling 在 1440p Quality 模式与 DLSS 4 打平；4K / 性能模式 N 卡仍略好，但差距远小于 FSR 3 时代。Digital Foundry 确认「很多场景能 toe-to-toe」
  • 最大短板：无多帧生成：DLSS 4.5 有 6X 多帧生成（每渲染帧最多插 5 帧）+ 动态多帧生成；FSR 只有普通帧生成（插 1 帧）。极限拉帧率 / 高刷电竞 N 卡仍明显强
  • 兼容型号可使用对应功能：RX 9060 XT 是 RDNA 4，完整支持 FSR Redstone 四项；FSR Upscaling 4.1 已下放到 RX 7000，但原生 RDNA4 显卡 享全套——这是选 A 卡的真实红利
  • 结论：选 A 卡不亏。超分 / 光线重建 / 全局光三块已补齐，仅多帧生成差一代；主打 1440p 天花板游戏 + 大显存保值的场景，短板影响小。原「大显存 + 锁价 + 性价比」决策逻辑不受影响
参考提示：超分辨率和帧生成功能依显卡、驱动和游戏而异，启用前应核对具体支持范围并比较画质和延迟。

主板 H/B/Z 与代数怎么读：一个字母定档位，首位数字定代数（附 5 处修正）

参考《主板芯片组 H/B/Z 前缀到底啥意思》与 Intel ARK，比较主板芯片组、内存超频及处理器支持。

  • ✅ 对的部分：H = 入门 / B = 主流 / Z = 高端；Z 独享 CPU 超频；不超频的 U 配 B 档完全够用，省下的钱加显卡更值
  • 修正①「H 系列不支持内存超频」只对 H610 成立：Intel ARK 官方规格——H610 内存超频栏为空（锁死不能开 XMP）+ PCIe 仅 3.0；但 H670 / H770 是支持内存超频的（标 Memory），只是零售少见。别把低端 H610 的特征当成整个 H 系列
  • 修正②「数字怎么读」那段写错了：正确读法是——字母后首位数字 = 代数（600 系 = 12 代时代 / 700 系 = 12-14 代 / 800 系 = LGA1851 Core Ultra 200S），后两位是档位编号。所以 B660 与 B760 是「不同代」，不是「同代后缀不同」；而且同代内决定档次的是字母（H < B < Z），不是数字大小
  • 修正③「现在主流是 7 系」已过时：2026 年 Intel 新平台主流是 800 系（H810 / B860 / Z890，LGA1851）、AMD 是 800 系（B840 / B850 / X870）。但走 LGA1700 + DDR4 路线的话，700 系（B760）才是正确解；800 系是 DDR5 专属，跟过去等于手上的 DDR4 全废
  • 修正④「新 CPU 不能配老主板」要分两层：跨插槽绝对不行（LGA1700 与 LGA1851 针脚不同、硬插会烧）；但同插槽内老主板刷 BIOS 可支持新 CPU（B660 刷 BIOS 能上 14 代、B650 刷 BIOS 能上 Ryzen 9000）。买前查厂商 CPU 支持列表 + 最低 BIOS 版本
  • 修正⑤漏了 AMD 与 Intel 的关键差异：AMD 的 B 系列也支持 CPU 超频（PBO），只有最入门的 A620 / B840 不支持；Intel 则把 CPU 超频独占给 Z。所以「AMD 逻辑跟 Intel 差不多」是错的——AMD 主流 B 档就能超 CPU，两家的性价比逻辑不一样
示例：B760 = 700 系，原生支持 12 代 Core 免刷 BIOS；内存超频有（可开 XMP 跑 3200），CPU 超频无——带 K 的 U 装 B760 不超频，是常见取舍（回看 H610 vs B760：H610 连内存都锁 3200，B760 可开 XMP + 4 内存槽 + 更强供电）。文章「B760 一般 2-3 个 M.2」属实，部分 M-ATX B760M 可给到 3×M.2 + 4×SATA + PCIe 5.0 x16。⚠ 别被「带 K 必须上 Z」带跑——不超频的话，Z790 多花的几百块是零收益。

机箱怎么挑：先对板型，再逐条算「六项差价」（附 3 处数字修正）

参考《几十块和上千块的机箱，差的不是铁皮》：比较板型、散热、做工和其他机箱需求。

  • 规则一句话：机箱标注的「支持版型」必须 ≥ 主板版型（ATX 箱能装 M-ATX / ITX，反过来物理上不可能）。板型尺寸是死标准：ITX 170×170 / M-ATX 244×244 / ATX 305×244 / E-ATX 305×330mm。挑机箱第一眼看「支持版型 + 显卡限长 + 散热器限高」，不看外部长宽

  • 正压风道：进气量 ≥ 排气量，灰尘从缝隙往外溢而不是往里钻 → 内部常年干净、少清灰。排气多于进气＝负压＝缝隙全在吸灰
  • 版型选购：桌面不挤 → ATX 中塔（兼容最强、散热最从容，2026 年 200-300 元就能买到网孔前面板 + 0.6-0.8mm 板的「水桶箱」）；小桌面/单显卡 → M-ATX 性价比常更高（M-ATX 主板能塞进 ATX 机箱，机箱宁大勿小）；ITX 要交三重税（机箱贵 + 主板贵 + 难装散热挑），新手别碰；E-ATX / 全塔普通玩家别碰
  • 避坑清单：显卡 >320mm 先量限长；高塔风冷（160mm+）先量散热器限高；别买「全玻璃封底」海景房（十有八九变闷罐，只有底部满网孔 + 顶部全开才兼顾颜值）；ITX 别为省钱买薄箱（共振能让你后悔）
  • ⚠ 修正①：「理线能降 7℃」存疑——原文前半说线材乱塞让 CPU 高 7℃、后半又说规范理线降 2-4℃，自相矛盾；可复现的实测里线材对温度影响多在 1-3℃。理线的真正价值是风道通畅 + 好维护，别把 7℃ 当硬指标
  • ⚠ 修正②：「满载噪音压到 26-30dBA」偏乐观——26-30dBA 基本是轻载 / 静音优化的自有噪音口径；225W 级显卡 + 125W CPU 的游戏机满载、1m 实测通常 35-45dBA。吸音棉的真实收益就是上面说的 2-5dBA，不可能把满载压到 26-30
  • ⚠ 修正③：「机箱预算占总价 5-8%」是通用启发式、不是硬标准——正确顺序是先满足硬指标（网孔前面板 + 显卡限长 + 散热器限高 + 背线仓 + 防尘网），再决定要不要为静音 / 厚板 / Type-C 加钱。入门预算里把 ¥129 的网孔箱硬拉到 ¥500+，是在削显卡和板U的钱
选购提示：机箱应核对显卡限长、散热器限高、板型、风道、防尘、背线空间和硬盘位；预算款还需关注板材厚度与接口。

耐听度自检与场景错配：一件设备「好」该怎么判（附价格锚点三读法）

参考《用了 299 的监听音箱后，我 2399 的哈曼卡顿水晶 4 就吃灰了》：按使用场景、听感和当前价格比较音箱。

  • 判据①·耐听度是唯一的自检标准：不看参数、不看价格，只问一句——我能连听 / 连用 2-3 小时不累吗？「第一耳朵震撼」是营销陷阱：V 型调音、轰头低频、狂暴灯效，前五分钟很爽，半小时后说不上哪不对，就是不想再用。那不是好，是吵。
  • 判据②·「猛」只是量，「好」才是质：低音猛 ≠ 低音好，可以推广成——任何参数的「猛」都只是量。机制上这叫掩蔽效应：低频一多就把中频盖掉一层（人声像隔着东西传来、乐器分离度变差、弦乐线条被余震糊掉）。量压过质的设备，一律不耐听。
  • 判据③·场景错配 > 价格错配：水晶 4 是「客厅 / 聚会 / 摆着有面子」的氛围件，MR4 是「坐桌前认真听」的近场件。作者不是从 2399 降级到 299，而是换回了对的使用场景。「贵的那件不好用」十有八九不是它差，是它被放错了场景——买之前先明确「我在哪、用什么姿势、用多久」。
  • ⚠ 价格锚点三读法：文章用「2399 vs 299」讲了 8 倍的故事，两个数都是非常规价——① 首发价 ≠ 今天的对比价（水晶 4 首发约 ¥2399-2499，现价已跌到 ¥1556）；② 脉冲低价 ≠ 常规价（MR4 京东常卖 ¥404-450 / 历史最低 ¥357，文章的 299 是 PDD 补贴刷到的）；③ 所以真实常规对比约 ¥1556 vs ¥404，约 3.8 倍，不是 8 倍。比价必须比「当前常规价」，别拿任一端极值当基准。
  • ⚠ 术语要能落到可查指标：「监听」不是受标准保护的词，谁都能标。MR4 有德国 KLIPPEL 认证 + near-flat 定位，属入门桌面监听，不是录音棚监听。判断一件东西够不够格，看有没有可查的测量依据（频响 / SNR / THD / 认证），而不是看那个词高级不高级。
  • 反方意见必须一起收（不然会被带跑）：入门设备的取舍是「某一面刚好满足你」，不是全面替代——「300 有 300 的声音，3000 有 3000 的声音」；中正平和 ≠ 平平无奇，均衡与无聊是两回事；小尺寸单元受物理限制（4 寸低频下潜有限，要真量感得 6.5 寸以上 + 独立功放）；MR4 还有底噪偏大、挑前端、无蓝牙这一类实测反馈。
选购提示：比较价格时区分日常价格、厂商建议价和二手交易价；根据需求判断外观、性能和售后是否值得额外支出。

从「找答案」到「不需要再找」：可闻性阶梯与试错的定价

选音频设备时，先明确使用场景，再比较不同投入是否带来可闻的收益。可参考耳机展及 HiFi 消费相关讨论。

  • 判据①·可闻性阶梯：换能器 > 前端 > 线材（盲听可复现性递减）。硬依据：入门一体机在 300Ω 平衡上的实测推力 —— 飞傲 K15 约 700mW / 山灵 EH3 约 750mW / 高登小夜曲约 760mW / 飞傲 K9 AKM 约 780mW / 拓品 DX5 II 约 990mW，最强与最弱仅差约 1.4 倍。所以「换前端换来换去听不出决定性差别」是必然结果、不是耳朵不行 —— 那叫同档平移。预算优先给换能器（耳机 / 音箱）与空间，别给线材。
  • 判据②·同形态边际递减、跨形态才有台阶：同为平板大耳换机（如中端新款对照手上旧款）常常「一耳朵听不出」；真正有感的是跨形态 —— 动圈 → 平板 → 静电、耳塞 → 大耳、耳机 → 音箱。先跨形态，再谈同形态升级；同形态里加钱买到的多半是「爱好税」。
  • 判据③·响度效应：展会嘈杂 → 开放大耳要开到很大音量 → 「声压大、听到的细节更多、本能觉得更好听」—— 这是等响曲线 / 响度效应在起作用，是音量差，不是器材差。噪声环境里根本没有做对比的条件，「听不出区别」是环境问题，不是耳朵或器材的问题。
  • 判据④·计算完整成本：做预算时，应将设备试用、更换及转售可能产生的支出一并考虑，而不只计算最终保留的设备。
  • 判据⑤·三笔隐藏账：① 前端（「买回来要推吧」→ 小尾巴 → 便携台机 → 入门台机，累计四五千）；② 线材配件（「原线不够好」→ 平衡线 / 转接头 / 收纳，不知不觉一千出头）；③ 进出试错（退货、挂闲鱼，就算不亏钱也搭进时间精力，且必然亏钱）。
  • 判据⑥·试错的定价：能落成一条明确「排除项」的才叫学费。正例 —— 某台一体机的低音量电位器偏音让人明确「这个不能忍」；某副耳塞低频轰头让人明确自己的口味；几台播放器退货后确定「手机 + 小尾巴才是最省心」。反例是不设对照的「换线 AB」 —— 没有盲听对照，试出来的往往是预期而不是听感。判据：这次试错让我永久排除了什么？答不出来，就是真浪费。
  • 判据⑦·终止判据：器材的尽头不是旗舰，是你确定自己不需要再找的那一天。可操作化成两句 —— 能用一句话说清「我为什么不需要它」，就是退出点；反过来，「再上一个台阶要花好几倍的钱，而在我的使用场景里根本感知不到」，就是已经到达平台期的信号。
  • ⚠ 一处保留（别照单全收）：作者对评论区「双盲挑战」的回应（「完全主观感觉，你如果不认可就是你对」）属回避。正确切分不是「听感玄学 vs 科学」，而是差异有大小之分 —— 换能器 / 空间可盲听复现，线材 / 前端多数不可靠复现。承认这个切分，才让「哪笔钱该省」变清楚。另外「试错不是浪费是学费」缺一个前提：试错必须产出可迁移的偏好信息（见判据⑥）。

技巧 87

DP 还是 HDMI：主屏走 DP，别碰 HDMI

DP 与 HDMI 使用不同的传输技术；DP 1.4 原始速率可达 32.4Gbps，HDMI 2.0 为 18Gbps。选线时应核对设备及线材实际支持的规格。

  • 硬件核对：分别确认显卡、显示器和线材接口支持的分辨率、刷新率与带宽。
  • 带宽账：1080p@240Hz 需约 14.3-14.9Gbps；DP 1.4 有效 25.92Gbps 余量充足，HDMI 2.0 有效约 14.4Gbps 顶满甚至可能跑不到 240Hz。
  • 结论：主屏走 GPU 的 DP 口 → 显示器 DP 口，开 FreeSync；随屏附赠 DP 线直用（连 DP1.2 线都够）；HDMI 线仅作副屏 / 游戏机备用。别买任何「认证品牌线」。
参考提示：显示器分辨率、刷新率和接口规格应以完整型号及厂商资料核对，不要混用相近型号的参数。

技巧 97

内存频率和时序怎么比：CL 是拍数不是时间，先换算成 ns 再比

参考《买频率还是买时序？游戏帧数实测告诉你》：内存延迟（ns）可按 CL × 2000 ÷ MT/s 估算。

  • 都换算成 ns 再比：6000C30=10.00ns、6400C32=10.00ns、7200C36=10.00ns、4800C40=16.67ns、DDR4-3200 C16=10.00ns、DDR4-3600 C16=8.89ns、DDR4-2666 C19=14.25ns。DDR4-3600 C16 的延迟低于绝大多数 DDR5 条→ DDR5 赢在带宽（6000=96GB/s）不赢在延迟。
  • 带宽 = MT/s × 8 × 2（双通道）：DDR4-3200=51.2GB/s、2666=42.7GB/s、2133=34.1GB/s；DDR5-6000=96GB/s。
  • AM5 守 6000（金士顿 X870E+9950X AIDA64）：6000C30 Gear1=77.7ns、6400C32 Gear2=79.9ns（反而变差）、8000C38=75.7ns → 6400 是负收益，须到 7600-8000 才靠带宽翻回来。
  • 分辨率越高内存越不值钱（TechPowerUp）：720p 提升 5.1% / 1080p 3.8% / 1440p 3.2% / 4K 0.5% → 高刷低分辨率网游才是内存收益区，4K 直接无视。
  • 别拿频率数字直接比：CL 不同则频率高 ≠ 延迟低；看 1% Low 比看平均帧重要；平台有上限，别超平台甜点。
DDR4-3200 C16 标称就在 10ns 甜点线上，但不开 XMP 就跑 JEDEC 默认档（2133/2666）≈14ns，白扔约 30% 延迟 + 20-50% 带宽；1080P 高刷网游正是内存收益最高区间。开 XMP 后跑 MemTest86 / OCCT 20-30 分钟验证；DDR4 平台（非 Z 芯片组）别顺手冲 3600，3200 是甜点。

技巧 62

月度行情月报的正确读法：先印证既有决策，再找真正的行动项

「9 月装机走向与推荐」这类月度市场分析，价值不在它推荐的配置单，而在用行情判断价格趋势与下单时机：

  • 行情五条（8 月实况）：① 独显全系暴涨，不分产品线（新架构 / 在产上代 / AMD / Intel 无一幸免），越高级、显存越大涨越凶；② DDR5 整体大涨，DDR4 有涨有跌（非单边上涨）；③ SSD 整体平稳但维持高位；④ 机械盘部分降价但仍高位，建议 4TB 起；⑤ 同配置装机成本同比涨 20%~70%，内存越大、显卡越高档涨越多
  • 读月报先对账口径：同是「固态价格」，廉价 SATA / PCIe 3.0 盘与主流 PCIe 4.0 NVMe 是两个价位（如 1TB 约 800 vs 850~950），先分清品类再比对，别看见数字不一样就以为谁记错了
  • 第一步·印证：对照预算、平台兼容性和实际容量需求。若条条吻合，说明不必仅因市场推荐而改变符合需求的方案
  • 第二步·找行动项：月报里真正有用的是你还没买的那件的价格方向。已购 / 已到货的件再涨也与你无关，只有待购件的降幅才决定要不要现在下手
  • 最大的坑·被「便宜套装」带跑：月报常推性价比套装（某代 U + 新主板套装便宜几百），但先看它绑不绑内存换代——若新平台强制 DDR5，而你已持有 DDR4，省下的 CPU 钱会被整根内存废掉吃掉。算总账：省下的 CPU 差价 vs 废掉的内存沉没成本，哪个大
参考提示：阅读行情时结合尚需购买的配件、总预算和兼容性，避免只因套装便宜而忽略更换内存等额外成本。

技巧 76

渠道分品类决策：该问的不是「哪个平台便宜」，是「哪个平台扛得住售后」

按商品价格、售后和购买渠道比较：

  • 判据①·把售后折进价格：真实到手成本 = 商品价 + 出问题概率 × 维权成本。显卡 / 电源 / 主板 CPU 这类件单价高、一次故障就顶回几百块差价，必须走能开票、能上门、支持 7 天无理由的渠道。
  • 判据②·低值配件反过来算：机箱 / 散热 / 键鼠单价低，坏了多半「懒得退、直接换」，维权成本反而高于差价本身 —— 这类件去补贴价渠道是划算的。
  • 判据③·分品类下两张单，别凑单：为了凑满减把所有件塞进一个平台，等于用「高价件的售后」去换「低值件的几十块优惠」。凑单省的钱是显性的，售后丢的东西是隐性的。
应用示例：高价件（显卡 / 电源 / 主板 CPU）走自营渠道，低值件（机箱 / 散热 / 键鼠）走补贴价渠道。要警惕的是「顺手凑单」：若为凑一张券把电源挪到无售后主体的链接，省下的几十块撑不住一次换新。
技巧 77

「刷券术」的真相：机制是真的，功法是假的

优惠券触发条件因平台和活动而异，固定步骤不一定适用于所有账号和商品。

  • 判据①·券由「行为」触发，不由「手法」触发：平台按账号活跃度 / 停留时长 / 比价行为做分层定价，券是这套分层的输出。同一套动作换个人做，结果就可能不同 —— 所以「照抄七步」必然有人成功有人失败。
  • 判据②·两份攻略互相打脸就是伪科学的标志：一份说「快速下单能诱发挽留券」，另一份说「反复刷新反而没券」。方向都定不下来，说明这套「功法」没有因果链，只是幸存者叙述。
  • 判据③·真正稳定的只有两条：① 加购物车不结算，隔天再看（时间间隔 > 动作花活）；② 换账号 / 换设备比价（价格歧视按账号分层，换号才看得出自己是否被「杀熟」的那一档）。
  • 判据④·留证有依据，但别为等券推迟下单：2026-04-10 起施行的《互联网平台价格行为规则》第 15 条已明确禁止「同货不同价」，遇到明显差别定价截图留证即可。但价格到了心理价位就买 —— 等券的机会成本通常高于券本身（呼应技巧 67）。
应用示例：只在补贴价渠道买低值件，就吃不到「刷券」的收益，也自然躲开它的坑。可落地的只有两条：① 加购后晾一天再看价，别当天冲；② 两个平台换账号或换设备对一次同款价，确认自己没被分层定价。

传闻不是行情：5090 停产风波的正读法 +「按件拆涨价桶」

  • 判据④·二手不再是避风港：本轮二手同步跟涨（RTX 5080 二手 6 周 +27%，商家称「用了两年的卡几乎原价回收」）。「等二手降价」在结构性短缺里同样不成立——便宜只能靠挑品相和砍价，不能靠等。

千兆链路四环木桶：光猫口 → 路由 → 网线 → 网卡，最短一环决定实测网速

参考《1000M 宽带最容易白办的 5 种家庭布局》，按光猫网口、网线和无线覆盖顺序排查网络。

  • 判据①·四环木桶：一条链路有四段 —— 光猫 LAN 口 → 路由器（每一级 WAN/LAN）→ 网线 → 电脑网卡。任一段是百兆规格，全链就被端口自协商拉到双方最低速率（百兆口的物理上限就是 100BASE-TX）。先找最短那一环，再谈换设备。
  • 判据②·光猫 LAN 口（文章没提，但最该先查）：多数运营商光猫 LAN1 = GE 千兆口（路由器专用），LAN2-LAN4 = FE / IPTV 百兆专用口（硬件锁 100M，只给机顶盒）。路由器主线插错 → 全屋手机电脑一起被锁在 90-100M。实测案例：90M → 换到 LAN1 + 光猫路由一起断电重启 → 920M。认字即可：找 LAN1 / GE / 千兆 / 10/100/1000M，避开 FE / 百兆 / IPTV。若四个口全是 FE，打运营商客服换千兆光猫（多数免费）。
  • 判据③·940Mbps 就是满速，不是「没跑满」：千兆宽带有线实测 900-950Mbps 属正常。协议开销约 5-8%（PPPoE 8 字节报头 + 以太网帧头 + IP/TCP 头），940Mbps 已接近物理极限。拿「跑不到 1000」去投诉或换设备，方向一开始就错了。
  • 判据④·网线：8 芯全通 + Cat5e 起步：千兆要4 对线全双工收发，只通 1/2/3/6 芯（四芯）只能退 100BASE-TX。选线三看 —— 类别（Cat5e 在 30m 内就能跑千兆，家装预埋起点是 Cat6）、芯数（必须 8 芯全通）、材质（无氧铜；铜包铝 CCA 电阻大、易氧化，便宜但别埋墙）。⚠ 别买 Cat7 / Cat8：七类非 IEEE 标准、需专用接口，八类是 30m 内的数据中心短跳线，家装电工做不了屏蔽工艺。
  • 判据⑤·布局三原则：中心化 / 高置化 / 空旷化：路由器放户型中央、离地高、少遮挡且通风的位置（厂商官方建议也是这三条）。弱电箱是配电房不是发射塔 —— 金属箱体等同法拉第笼，直接屏蔽 Wi-Fi；箱内又小又闷（散热差、夏天容易死机断网）。箱内只放光猫 + 交换机，主路由放客厅等开阔位置。
  • 判据⑥·覆盖与回程：加路由 ≠ 解决覆盖：一台路由器不可能覆盖全屋，瓶颈是墙体衰减。无线中继 / 信号放大器：单频、双频中继的回程占同频，带宽约减半（2026 年三频 Mesh 用独立回程频段已可接近有线回程，但打游戏仍有 1-3ms 抖动）→ 优先有线回程 Mesh 或 AC+AP。
  • 判据⑦·预埋要留冗余（装修只有一次机会）：每个点位至少 1-2 根（1 用 1 备），客厅电视墙 2-4 根，书房 2 根起步，吊顶留 1 根给吸顶 AP。墙内网线一旦封堵几乎无法更改 —— 多埋几十块，省下将来砸墙。
  • 判据⑧·行动顺序：先改布局，再换设备：换设备是最贵的解法，也常常是错的解法。体检顺序固定为 光猫口 → 路由器各级 → 网线 → 终端网卡 → 最后才轮到换路由。有线基线法：拿网线直连光猫 GE 口跑一次测速（运营商官方测速 / iperf3），先确定「宽带到底给了多少」，再判断是自己的问题还是运营商的问题。
参考提示：网线应核对线序、线材类别、质量和长度；低延迟场景可比较有线和无线连接的实际表现。

双屏割裂感五痛点：让眼睛累的不是分辨率差，是设置没拉平

双屏使用出现显示问题时，先检查连接方式与系统设置，再判断是否需要更换设备。

  • 判据①·分辨率差异本身不伤眼：无证据表明不同分辨率混用伤眼；高 PPI 文字边缘更平滑，读小字反而更省眼。方向是反的——27 寸 1080P（81.6 PPI / 点距 0.31mm）才是疲劳源，换 2K（109 PPI / 0.23mm）是减负。刷新率 240 vs 180Hz 人眼无感，不构成问题。
  • 判据②·真正的元凶是缩放不一致：2K 屏若保持 100% 缩放，文字物理大小比 1080P 屏小 25%，两屏切换读小字时眼睛不断重新适应——这才是「不舒服」的来源。对策：27 寸 2K 设 125% 缩放、27 寸 1080P 保持 100%，两屏文字物理大小趋近一致。
  • 判据③·亮度 / 色温不匹配比分辨率差更扰人：两块屏亮度色差大时，大脑切换焦点要重新校准。对策：亮度色温拉平（都调默认或都 50% 左右），别一个刺眼一个暗。
  • 判据④·窗口跨屏变形 + 高度差 + 鼠标跳变，各有一个对应解法：窗口从 2K 拖到 1080P 会变大变糊（接受 1-3 天适应期，读小字的任务固定主屏）；高度差用支架顶边对齐解决；鼠标穿越边界跳变，在 Windows 显示设置里拖动屏幕图标匹配物理摆位。
  • 判据⑤·软文的话术框架要认得：先把现有双屏定义为「割裂 / 不适」，再推出「一块屏解决所有问题」的万能药。遇到作者名 = 品牌名的内容，痛点描述可以参考，产品部分直接跳过。

全屋 WiFi 怎么选：网线 / 有线 Mesh / FTTR 决策树

全屋网络可按布线条件比较 FTTR、有线 Mesh 与其他方案。

风扇不是越多越强：有效换气看路径——五错装、正负压、冷排位置与 A/B 测风道

参考《机箱风扇装得越多，电脑为什么反而更热？》及 Digital Trends、be quiet!、ARCTIC、CORSAIR 的风扇和电源资料。风道效果应以具体机箱和实测为准。

  • 判据①·决定温度的是有效换气，不是扇数：冷空气有没有穿过显卡、CPU 供电和内存附近再离开；路径对了三四把也能很凉，路径错了十把只是花钱制造噪声（Digital Trends 原话：冗余堆叠风扇反而增加湍流）。
  • 判据②·五种错装先排查，别急着换散热器：① 对吹（前后 / 上下两股风迎面撞，热空气局部打转）；② 短路风道（顶部最前排把刚吸入的冷风直接抽走，显卡下半区断粮）；③ 排风太猛进风跟不上（只能从 PCI 挡板、侧板缝隙补气，灰尘进得快）；④ 障碍太多（冷排、厚滤网、乱线材——标称风量是理想条件下测的，不代表装机后）；⑤ 曲线绑错温度源（机箱扇只盯 CPU，不管 GPU）。
  • 判据③·正压防灰、负压散热强：数量相同 ≠ 进出风相等（滤网、冷排、转速、型号都改写结果），别用风扇数量判断风压；家用推荐轻微正压（进风略大于排风、进风口全带滤网），灰尘集中在滤网上后期好打理。
  • 判据④·冷排位置本质是一笔温度交换：前置 = CPU 直接吃室温空气更凉，但显卡 / 供电 / SSD 接到的是被冷排加热的「温风」；顶置 = 前部冷风先喂显卡再经冷排排出、路径更直，但 CPU 略吃亏。最该避免「前置冷排进风 + 顶部前端强排风」；已装错的解法是先关掉 / 压低顶部最前排那把，不必急着拆。
  • 判据⑤·五步测出谁在帮倒忙：① 先留基线（室温 / CPU / GPU 核心 / GPU 热点 / 显存 / 各扇转速 / 主观噪声）；② 一次只改一项（一次翻三四把，温度变了也不知道是谁的功劳）；③ 比较不只看最低温（温度、噪声、灰尘、稳定性一起看）；④ 看核心与热点的差（核心正常但热点很高 = 显卡散热接触问题，一起明显变高 = 整体进风不足）；⑤ 确定方向位置后再调曲线。最简 A/B：开侧板 vs 关侧板——开侧板明显更凉 = 机箱换气有问题，差异很小 = 查散热器 / 硅脂 / 环境温度。
  • 判据⑥·买风扇时数量排最后：先看尺寸和用途（风量扇给开放区、静压扇给冷排 / 滤网），再看灯效和套装；最低稳定转速比最高转速更重要（电脑大多数时间不在满载——Pure Wings 3 的官方卖点正是低转速安静运行）；海景房为统一灯效把侧面 / 底部 / 顶部装成同一方向最容易翻车（全进风或全排风），反叶版本买前确认风向；升级顺序 = 清灰理线 → 调方向 → 优化曲线 → 替换关键位置风扇 → 最后才加数量。
落地做法：普通中塔从「前部进风 + 后部排风 + 顶部靠后排风」起步通常最省心；顶部前排排风会截走冷风，宁缺毋滥；纯游戏机的机箱风扇曲线优先参考 GPU 温度（或 CPU / GPU 取高），别只盯 CPU；机箱放桌面 / 地毯时确认底进风口不被堵死；买风扇先看最低稳定转速与风向，数量排最后。
技巧 99

内存真实延迟公式：CL×2000÷频率，DDR4-3200 C16 已 = DDR5-6000 C30 甜点，别为低位加钱

参考：2026 科普文章《为了内存的低时序，到底值不值得加钱？》（装机猫）。

  • 真实延迟公式属实：ns = CL×2000÷MT/s（= CL÷频率×2000）；可用于估算
  • 甜点延迟档位属实：DDR4-3200 C16 = 10.0ns、DDR4-3600 C18 = 10.0ns、DDR5-6000 C30 = 10.0ns、DDR5-6400 C36 = 11.25ns——三者同延迟
  • AM5 甜点 C30 属实：DDR5-6000 CL30 是 1:1 UCLK 甜点；超 6000 切 1:2 罚 +10~12ns（裸 CAS ns ≠ 总访存延迟，高频率低 CL 宣传要带这滤镜）
  • 文章偏差·补 K/非 K：文章把“DDR4 老平台”泛化劝退，未区分 K/非 K。非 K 锁 VCCSA(0.95V)，3200 稳、3600+ 只能 Gear2（延迟反噬）；K 系（如 12600KF）不锁 SA，B760 D4 可稳推 3600~4000 Gear1，网游帧高 5-8%
  • 低时序对 1% low 帮助最大：竞技网游最低帧/跟手感受益，3A 平均帧几乎无感
参考提示：内存调整前核对主板和处理器支持的规格；启用配置后应进行稳定性测试，评估实际收益。
技巧 100

固态颗粒 TLC vs QLC：差距全在缓外速度，系统盘/工作盘认准 TLC，纯游戏/冷数据 QLC 可

参考：2026 科普文章《买固态别只看容量：TLC 和 QLC 的差距，全在“缓外”那一下》（装机猫）。

  • 颗粒位数属实：TLC 每格 3 bit、QLC 每格 4 bit，QLC 同容量用更少 die → 更便宜（底层逻辑对）
  • 寿命档位属实但有偏差：TLC P/E 约 1000-3000、QLC 约 100-1000；文章写 QLC 500-1000 偏乐观，低端 QLC 仅 100-300
  • SLC 缓存+缓外掉速属实（最硬核）：QLC 标称快是伪 SLC 缓存撑的，缓存用完直写掉到 50-150MB/s（甚至几十 MB/s），比机械盘还慢；TLC 缓外仍 300-1500+MB/s
  • “读取不伤寿命、写入才伤”属实：读不耗 P/E，重度写才折寿
  • 文章偏差·恐吓过重：“存不过三年”是重写入场景的吓法——普通只读/轻度写用户 QLC 寿命（150-300TBW）按 ~50GB/天算能用几十年，真实短板是缓外速度不是寿命
  • 厂商文字游戏属实：详情页只写“高速颗粒/原厂颗粒”回避 TLC/QLC，系统盘/工作盘一律默认 TLC
落地做法：系统盘、生产力/工作盘认准 TLC（缓外仍 300MB/s+，寿命 1000-3000 P/E）；纯游戏库、冷数据/影视照片备份等只读为主场景，QLC 大容量盘性价比高、寿命够用（读取不耗寿命）。买盘先看具体型号颗粒方案，别信详情页“高速颗粒/原厂颗粒”模糊话术；重点看缓外直写速度而非标称顺序写速度，盘用到 60-80% 缓外会更早掉速，留 10-20% 余量。
技巧 101

双显卡搭配避坑：现代无 SLI/CF 不叠加帧数，同型号双 N 卡最稳，N+I 直接避开

参考：2026 科普文章《双显卡怎么搭配才省心，5 种组合 9 项实测》（装机猫）。

  • 现代双卡 ≠ 加速：SLI 自 RTX 20 停更新 profile、RTX 40/50 全无 NVLink、DX12 Multi-Adapter 几乎无游戏支持——双独显只是「各接一屏」的多适配器场景，游戏帧数不叠加
  • 五组实测星级方向可信：N+N 4.5 > I+I 4 > A+I 3.5 > N+A 3 > N+I 1.5（单平台单次实测，精确到个案要打折）
  • N+I 问题最集中：游戏报错、音画不同步、跨屏严重卡顿、剪映不走指派——多 GPU 跨卡软件冲突有 OBS 官方 wiki 等权威佐证
  • Arc 系通病：老游戏把 B580 误判为核显（WDDM 枚举命名割裂，DirectX Adapter Name 仍报旧名）；B580 在芯片组 ×4 槽可能点不亮（个案，文章已自我限定不能泛化）
  • 系统指派 ≠ 全引擎跟随：Windows 图形设置指派后，软件自己的 AI/预览等任务仍可能走另一张卡——以任务管理器实际占用为准
  • 程序默认用卡跟主显示器走：默认用卡与主显示器接在哪张卡相关；性能更强或插第一槽都不保证自动获得优先权
落地做法：现代平台双独显不叠加游戏帧数（SLI/NVLink/CF 已退出消费级），只是各接一屏的多适配器场景；同品牌同型号最稳，混搭优先 A+I、避开 N+I（游戏报错/音画不同步/跨屏卡顿）；Arc 系可能被老游戏误判为核显；多 GPU 下 Windows 指派不一定让软件全部引擎跟随，以任务管理器实际占用为准；程序默认用卡与主显示器接哪块卡相关。加卡原则：同品牌同型号优先，别为「加速」买第二张。

技巧 14

刷新率 ≠ 帧率

看到的流畅度 = min(刷新率, 帧率)：

  • Hz = 屏幕每秒刷几次（显示器参数）
  • FPS = 显卡每秒渲染几帧（显卡性能）
  • G-Sync：刷新率跟显卡帧率智能匹配
  • 竞技 FPS 开 240Hz；3A/像素游戏开 G-Sync 自适应
选购提示：在系统和游戏中设置显示器支持的刷新率；按显示器和显卡支持情况启用可变刷新率。
技巧 60

新机点亮 BIOS 三件套：XMP + Above 4G Decoding + ReBAR/SAM

2027 大作官方建议项（Fable 配置表），主流板卡均支持，装机 30 秒白捡帧数稳定性：

  • XMP：内存标称频率（DDR4 3200/3600）出厂默认只跑 2133/2400，不开白瞎——BIOS 一键开
  • Above 4G Decoding：必须开，它是 ReBAR 的前置开关
  • ReBAR（可调整大小 BAR）：让 CPU 一次读满显卡全部显存，3A 帧数更稳、不忽高忽低；AMD 卡这边叫 SAM（智能存取内存），同一样东西
  • 顺序：先进 BIOS 开 Above 4G → 再开 ReBAR/SAM → 最后开 XMP，保存重启
选购提示：启用 BIOS 功能前应检查主板、显卡和操作系统的支持情况，再按厂商文档设置。
技巧 63

为什么厂商都让你走 DP 不走 HDMI：三条通道 + 带宽余量

参考《DisplayPort 一致性测试指南》，了解家用设备相关的接口、链路和线材选择。

  • DP 三条通道各司其职：Main Link（4 条高速差分线，只传画面像素；档位 HBR 8.64 / HBR2 17.28 / HBR3 = 32.4Gbps 原始、25.92Gbps 有效载荷）；AUX（低压双向控制线，开机读显示器 EDID（能力表）与 DPCD（配置数据），再发起 Link Training 去协商速率）；HPD（热插拔检测，一插拔就通知显卡「设备变了」，重新协商一轮）
  • Link Training 是反馈闭环，不是写死：源端与接收端反复握手，按「当前这根线能稳住的最高速率」跑；线材或接口信号不够就自动降速 → 表现为偶发黑屏、闪黑、刷新率上不去。同一块显卡换根差线，体验能肉眼变差，根因就在这
  • TP2 / TP3 / TP3_EQ 是什么：VESA 的合规测试点，其中 TP3_EQ 测的是高码率下的均衡（equalization）能力——能否扛住信道衰减、让 Link Training 在 HBR3 稳过。家用结论只需一句：买 VESA 认证 DP1.4 线（¥15-25），别买无名 ¥5 线
  • 带宽账（1080p@240Hz 8bit ≈ 需 14.3Gbps）：DP1.4（HBR3）有效 25.92Gbps → 余量 11.6Gbps；HDMI2.0 仅 18Gbps → 余量 3.7Gbps，贴脸跑；一旦开 10bit / HDR，HDMI2.0 直接爆带宽，DP1.4 仍富余
  • FreeSync 是 DP 的原生协议：走 DP 显示 FreeSync / Adaptive-Sync；走 HDMI 只显示为 VRR（套一层兼容）。高刷屏不开 VRR ＝ 白买高刷
示例：主流中端显卡常给 2×DP + 1×HDMI 三输出，但不少 1080P/2K 高刷屏的 HDMI 口只到 2.0——HDMI 路径被显示器这头锁死在 18Gbps，DP 路径才跑得满 HBR3。装机日：主屏走 DP 口并开 FreeSync、副屏走另一 DP 或 HDMI2.0；线材认准 VESA 认证 DP1.4（¥15-25），二手屏大概率不配线。
技巧 66

旧盘从笔记本搬到台式机：要不要重装系统？

旧系统盘迁移到另一台电脑时，结论先说：技术上多数能直接开机，但「能开机」≠「干净可用」。动手前先想清三件事：

  • ① 激活大概率会掉：品牌笔记本自带的 Windows 是 OEM 数字许可证，绑定原主板；换到台式机主板后多半显示「未激活」（右下角水印）。OEM 许可通常不可转移，微软账号「更换硬件」疑难解答救不回来 → 直接准备买新密钥（OEM ~¥80）
  • ② 驱动残留会捣乱：笔记本的芯片组 / 显卡 / 网卡 / 电源管理 / 读卡器驱动全都不匹配。Win10/11 能自动补通用驱动，但厂商专属软件（电源管理、原厂管家之类）会残留，轻则设备管理器一堆黄叹号，重则蓝屏 / 休眠异常。显卡驱动务必 DDU 净装（见技巧 13）
  • ③ OEM 预装残留：品牌笔记本自带恢复分区 / 管家 / 驱动包，占空间还可能冲突——直接迁移等于背着一套「别人的系统」在跑

三条路线，按推荐度排：

  • A. 全新重装（推荐，最干净）：先把数据备份走 → 台式机用 U 盘全新装 Win。⚠ 若这块盘是笔记本唯一的系统盘，拆下来笔记本就没了——所以备份必须在拆盘之前完成（移动硬盘 / 网盘 / 借家人电脑），别指望拆下来两头用
  • B. 保留数据 + 只重装系统分区：数据若单独放在 D 盘，格式化 C 盘重装即可，D 盘资料不丢
  • C. 直接迁移不重装（省 1-2 小时，但脏）：直插试开机 → 能进系统就 DDU 清显卡驱动 + 卸掉笔记本管家 + 补装台式机驱动 + 处理激活。有洁癖别选这条
示例：复用笔记本 NVMe 固态（M.2 2280 / PCIe 3.0 x4 这类）当台式机主盘时，注意四点：① 拆盘前先把数据备份到移动硬盘 / 网盘——若它是笔记本唯一系统盘，拆了就没系统，没有「就地备份」的余地；② 若笔记本还要继续用，得单独给它配一块新盘（提前算进预算）；③ 装机日最省心 = 用 U 盘做 Win 安装盘、台式机从零全新装（提前备一份 Windows 密钥预算），一次点亮即用；④ 想省事也可直插先试，能开机再补驱动 + 买密钥，不行再重装——但数据备份永远排在动手之前。
技巧 82

XMP 什么时候值得开：标称频率 ≠ 实际频率

DDR4-3200 这类标称 XMP 频率的内存，不开 XMP 会跑 JEDEC 默认档（2133/2666）= 降频使用。

  • 开法：BIOS 里开 XMP。首次开黑屏重启 1-3 次 = 内存训练，不是坏了；CPU-Z 内存页看 DRAM Frequency 是否到标称。
  • 开完必测：MemTest86 / OCCT 内存测试 20-30 分钟，或连打 1-2 小时游戏不崩。
  • 不要冲高频：非 K 锁 VCCSA，Gear 1 只稳标称档，再高须切 Gear 2。
  • 配合 FSR 更有意义：FSR 对带宽敏感；高帧率场景开 XMP 通常让最低帧 +3-8%。
技巧 85

点不亮排查顺序 + LGA1700 ILM 压板陷阱

无法开机时，可先检查电源、连接和主板指示灯，再按主板手册排查：

  • ① CMOS 放电是标准第一步：扣 CR2032 等 30 秒 / 短接 CLR_CMOS 5-10 秒，不是乱操作。
  • ② 真正起作用的是「重插」：断电放电 + 顺手把各部件重新插一遍；接触不良只会被「重新插紧」治好。
  • ③ LGA1700 最易没插紧 = CPU 压杆：风扇不转、完全不 POST。症状定位：CPU/压杆=风扇不转、内存没插紧=只认单条、显卡没插到底=主板亮但无信号。
  • ⚠️ ILM 压板压力不均高发：内存只认单通道 / 一开 XMP 就点不亮 / 整体不稳 → 先松散热螺丝，或换第三方 CPU 接触框架（¥30-80）；开 XMP 后点不亮第一怀疑 ILM 压力 + 内存接触，不是内存条坏。
  • ⚠️ 无核显 CPU：「最小系统法 + 主板视频输出」不成立，靠板载 4 个 Distributed Debug LED（停在 CPU/DRAM/VGA/BOOT 哪个灯就是哪环节）。

新卡到货验收 SOP：望闻问切 → 对暗号 → 上刑 → 听啸叫

二手验机的三步法同样适用于全新卡，只是「查什么」不同——照这套走能规避 80% 售后扯皮：

  • 第 0 步·全程录像：拆快递纸箱前就开录像，防电商 7 天无理由掉包 / 运损扯皮；视频证据比照片管用得多
  • ① 望闻问切（外观初检）：防静电袋密封完好、无二次热封痕；金手指呈均匀亮金色、无氧化发黑或明显磨损（轻微出厂插拔痕正常）；固定螺丝无拧痕滑丝；挡板无锈点掉漆；散热鳍片无大面积压痕；风扇叶片无歪裂、转动顺滑无异响；DP/HDMI 口无异物弯曲；供电接口针脚整齐
  • ② 对暗号（SN + 软件核验）：PCB 背面 SN ＝ 包装盒 SN ＝ 保修卡，三处必须一致 → 官网/官方小程序查出产日期（全新一般不超 3-6 个月，超期＝库存尾货或翻新） → GPU-Z 核对官方标称的流处理器数 / 显存容量 / 位宽 / Bus Interface，防刷 BIOS 假卡 → 看 GPU 运行时长（新卡应 ≈0 秒；显示数小时即被用过） → PCIe Link Width 应为 x16（掉到 x8 有问题） → HWiNFO 看待机温度，直奔 60℃+ ＝ 硅脂干涸或散热模组已废
  • ③ 上刑（压力拷机）：FurMark 甜甜圈满载 30 分钟，紧盯温度曲线是否平稳、有无花屏/黑屏/闪退，同时盯 Hotspot（热点温度） → 3DMark Time Spy 压力测试，帧生成时间波动应 < ±3% → 再实跑 3A 游戏 1 小时模拟真实负载
  • ④ 听啸叫（双扇入门卡必测）：FurMark 跑起来后贴近机箱听有没有高频「滋滋」声——啸叫通常不算保修但严重影响体验，7 天内可找店家退换
落地做法：任何新卡到货都按这套走：录像开箱 → 三处 SN 比对并拍照留证（日后个人送保要用） → GPU-Z 核对官方标称规格 + 运行时长 ≈0 → FurMark 30 分钟盯 Hotspot → 贴近听啸叫。不少品牌已开通 3 年保 + 个人送保，SN 照片与购买凭证务必留好（店铺跑路也能直营保）；啸叫或硬件异常争取 7 天内退换。
技巧 58

二手矿卡避坑：批量卡一律默认矿卡

千元二手拆机卡「真香」背后是深水，核心认知先立住：

  • 批量 ＝ 矿卡：同型号动辄几十上百张库存的「拆机卡」，别信网吧倒闭 / 工作室解散的话术；个人玩家淘汰只零星出现在闲鱼，能批量供货的 99% 来自矿场或重度使用的网吧 → 买二手显卡本质是买概率，店保 3-6 个月只是商家算好概率后的心理安慰剂
  • 水洗新 & 缝合怪：闻到奇怪化学清香、散热鳍片深处有白霜 ＝ 刚经历水洗 + 挡板除锈的翻新货；核心背部电容发黄是水洗也盖不住的老化 → 杂牌「全新翻新卡质保 5 年」往往是新 PCB 板 + 旧核心拼凑，价格还上浮 10%-20%，先担心这牌子能不能活过 5 年
  • 品牌机拆机卡同样按矿卡看：联想 / 戴尔 / 惠普的拆机卡，矿潮时被整批拔去挖矿、剩空壳当准系统卖 → 除非能确认是售后流出的全新备件卡
  • 型号红黑榜：✅ 真香区＝RTX 2060 Super（8G 显存压过同价 3050 8G）、RTX 3060Ti（比 3060 12G 还便宜却性能更强，典型反向甜点）；❌ 智商税区＝RTX 2060 非 Super（不如加一点上 Super）、GTX 1660（不如加一点上 1660S）；⚠️ 低电源退路＝GTX 1660 Super（仅 125W，200W 办公机电源带得动，只当能流畅跑 PUBG 的过渡件）
  • 电源是底线：品牌办公机电源多只有 200W 左右，根本带不动 2060 Super（175W）/ 3060Ti（200W） → 必须预留预算换靠谱的 400-500W 电源，否则点不亮或烧机
  • 心态决定体验：别把消耗品当传家宝——一张全新中端卡的钱能换好几张性能相近的二手卡，坏一张还有备用；理性看待低价、不贪便宜、做好随时「暴毙」的心理准备
参考提示：比较新旧显卡时应综合考虑价格、来源、保修、功耗、电源余量和实际运行状态。

装机日全流程验机：外观 → 型号 → 烤机 → 功能（附两处修正）

参考《新电脑到手先验机》，按外观、型号、压力测试和功能检查的顺序验机。

  • ① 拆箱外观（通电前，重中之重）：纸箱严重磕碰 / 挤压 / 泡水 → 拍照留存、严重直接拒收；查机箱钣金划痕变形、螺丝有无反复拧动痕；对照配置单先记下各配件型号，留待软件核对
  • ② 型号核验（上机后，先别装游戏、先别急着打驱动）：CPU-Z 核 CPU 型号与核心线程；GPU-Z 核显卡型号 / 显存 / 位宽 / 核心代号（防改卡假卡）；备一个装机 U 盘，拷好 CPU-Z / GPU-Z / CrystalDiskInfo（图吧工具箱整合包亦可）
  • ③ CrystalDiskInfo 核固态：看通电次数与通电时长，全新盘通常通电个位数次、时长几小时内；通电几百上千小时基本是二手盘。⚠️修正一：SMART 数据可被翻新清零，它只能「查出问题」、不能反过来绝对证明全新；且若你的固态是从旧机拆下复用的，通电时长天然很高，别拿「全新盘」标准去判它、更别自己吓自己
  • ④ 烤机压测（把暗病逼在退换期内）：单烤 FPU（CPU）10-20 分钟 + 单烤 GPU（FurMark）10-20 分钟，看温度、有无蓝屏 / 重启 / 花屏 / 闪退；烤机温度偏高属正常，只要不撞温度墙、不自动重启即可
  • ⑤ 功能检查：全部 USB 口、音频口、网卡 / WiFi / 蓝牙能否正常联网、风扇启停、灯光是否与描述一致
  • ⑥ 全流程录像：从拆箱到验机完整录，作为维权证据；一旦发现型号不符 / 二手件 / 硬件故障 → 立刻停手、联系商家，别确认收货
验机提示：新显卡的金手指可能有浅而均匀的出厂测试痕迹。检查时留意深划痕、氧化和烧痕，并结合包装、型号、售后记录和实际运行情况判断，不要只凭一项迹象下结论。
兵器谱使用方法：每次买新硬件前过一遍对应篇章；装机后遇问题先查实操篇；被文章/推荐带节奏时回识货篇；新硬件到货先照「装机测试篇」验机再签收。这 71 条是整个装机过程中从科普文章提炼的「还能再用」的判断框架，不是一次性结论。

🔧 装机后调试 · AMD Software 最佳实践
用法：装完系统 + 装好显卡驱动后，照下面的顺序调一遍即可。内容基于科普文章《AMD Software 最佳配置全攻略》（2026-07）+ 评论区模拟器专项补充，适用于支持相关功能的 AMD 显卡与高刷新率显示器。核心就四件事：显示设置调对 → 开 FreeSync → 开 FSR4 升级 → 关掉鸡肋功能。

① 基础准备

  • AMD Software（Adrenalin Edition）装完驱动会自动出现，系统托盘图标或右键桌面打开。
  • 首次启动 跳过快速设置，用默认配置起步，避免一开始改乱。

② 显示设置（最关键，很多人栽在这）

  1. Windows 刷新率拉满：系统 > 显示 > 高级显示，把高刷新率显示器拉到 240Hz。很多高刷屏默认还是 60Hz，这是「感觉不到高刷差别」的真凶。
  2. 开启 VRR / FreeSync：AMD Software 右上角齿轮 → 显示 → 开 Variable Refresh Rate。DP 口通常显示 FreeSync / Adaptive Sync，HDMI 显示 VRR。务必打开，撕裂和卡顿明显减少。
    落地做法：兼容显示器可通过 DP 开启 FreeSync；在模拟器高帧率场景下检查画面是否仍有撕裂。
  3. GPU Scaling 关：建议关闭（Win11 大多强制，留着也无害，除非你需要整数缩放）。
  4. 颜色深度 / 像素格式（超级重要）：默认 10-bit 最好；像素格式选 RGB 444 Full RGB（无颜色压缩）。没有 444 就降到 8-bit 再选。用黑电平测试图验证：背景纯黑、暗部清晰；发灰或黑压死就调 Full/Limited。
  5. 其他色彩增强全关：Display Color Enhancement、Custom Color 等保持关闭，保留最准色彩。

③ 模拟器专项（评论区补充）

  • 渲染模式：优先测 OpenGL+ 和 DirectX+，新版 AMD 驱动两者都好，看哪个帧率更稳就留哪个。
  • 显卡渲染：勾选 开启独立显卡 + 强制使用独显渲染。
  • 高帧率下务必开 FreeSync 消除微撕裂（见 ②）。

④ FSR4 升级（重点，适用于兼容的 RDNA4 显卡）

  1. FSR Upscaling Driver Upgrade：保持开启（默认开）。RDNA3/RDNA4 能把游戏内 FSR 3.1 升级到 FSR4，画质明显提升。
  2. FSR Frame Generation Upgrade：推荐开启（默认关）。AI 新版本画质更好、性能损失极小。
  3. 验证：游戏中按 Alt+R 打开覆盖层，看 FSR 状态显示 Active（绿色对勾）。部分游戏需手动选 FSR4 而非 FSR3。
