物理模型

回波功率由雷达方程决定：

Pr = Pt G² λ² σ / ( (4π)³ · R⁴ )
  • 岸线：陆地—水面交界按垂直结构增强（岸壁回波亮线，含 2 个距离门衰减）；
  • 陆地：杂波强度由 OSM 道路/铁路密度驱动（1376 道路段 + 303 铁路段加权栅格化，建成区亮、郊野暗）；
  • 水面：海（水）杂波 σ₀ 随海况与掠射角变化，近距强、远距弱，并叠加瑞利分布闪烁；
  • 桥梁 / 码头：作为强散射目标叠加（钢桁架桥与金属码头是内河雷达图上的显著回波）；
  • 船舶目标：内河钢质船为强散射体，回波叠加瑞利闪烁；仅在扫描线扫过时显影、靠余辉拖出尾迹，同样受 1/R⁴ 衰减与 STC 影响；
  • ARPA 跟踪：点击目标亮点即锁定，实时解算方位 / 距离 / 航向 / 航速与 CPA / TCPA（最近会遇距离与耗时），CPA 过近自动告警；
  • 距离衰减：严格按 1/R⁴ 计算；STC（灵敏度时间控制）开启时补偿近距增益，关闭可直观看到 R⁴ 衰减效应；
  • 接收噪声：热噪声随增益抬升噪底。

数据与边界说明

  • 地形底图来源：OpenStreetMap（Overpass API 导出，南京二桥—天河口段，约 34.9 km × 27.6 km，水域约 237 km²）；
  • 长江主江面由河道中心线按标称宽度缓冲生成，宽度未经实测校准；
  • 陆地杂波密度为建成度 proxy（道路/铁路越密杂波越强），非实测散射系数；跨江大桥按长度分级为强目标（≥1.5 km 最强）；
  • 船舶运动为程序化推演（固定种子生成，沿深水航道避岸航行，3–9 kn），非 AIS 真实船位；
  • 底图为开发调试用途，非验收依据；回波为简化物理模型演示，未与实船雷达录屏比对校准；
  • 雷达参数取典型船用 X 波段雷达量级（9.4 GHz / 波束约 1.8°），非特定型号实测参数。
⚠ 本作品为教学演示用途：地理数据来自公开地图，回波模型未经实船数据标定，不用于航行决策。
