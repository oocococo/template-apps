使用说明

存储方式 · 页面结构 · 全部功能

1数据存储方式

库存数据保存在应用数据库，登录后可在不同设备访问。可导出 JSON 备份并通过导入恢复。

{
  "id": "sp_1a2b3c",
  "brand": "Bambu Lab",
  "material": "PLA",
  "colorName": "哑光黑",
  "colorHex": "#1f2328",
  "netWeight": 1000,   "remaining": 780,
  "threshold": 150,    "diameter": 1.75,
  "logs": [{ "t": 1761…, "g": 20, "note": "手机支架" }]
}

数据库连接失败时请检查登录状态并刷新页面。

2页面结构

  • 顶部操作区：品牌标题 + 使用说明 / 数据菜单（导出、导入、示例数据、清空）/ 新增耗材。
  • 概览指标：耗材卷数、库存总余量（kg）、低余量预警数、库存估值，随数据实时刷新。
  • 低余量提醒条：有耗材触及阈值时自动出现，一键跳转到「只看低余量」。
  • 筛选工具栏：关键词搜索 + 材料类型 + 颜色 + 状态 + 排序 + 仅低余量开关 + 重置。
  • 耗材卡片网格：色标、材料/颜色、余量进度条与百分比、位置标签、登记使用 / 编辑 / 记录 / 删除。
  • 分布面板：按材料类型统计剩余重量，按颜色统计卷数。
  • 四类弹窗：新增编辑、登记使用、详情与使用记录、本说明。

3核心功能

  • 增删改查：新增耗材、点击卡片任意位置外露的按钮编辑、删除前二次确认、搜索即查。
  • 余量跟踪：登记每次打印消耗克数，余量自动扣减并写入时间线；也可直接校准读数、重置为满卷。
  • 低余量提醒：每卷独立阈值（默认 150 g），低于阈值卡片描边变黄、状态徽标标红、顶部提醒条汇总；用完（0 g）单独标记。
  • 分类筛选：按材料类型、颜色、状态筛选，可组合搜索与排序，筛选条件实时生效。
  • 导出备份：JSON 完整备份（含使用记录）、CSV 表格（Excel 可直接打开）、JSON 导入合并。

4建议用法

每卷耗材贴一张小标签写编号，打完一个件就在卡片上「登记使用」；阈值按你常打的单件用量设（例如单件约 60 g，可设 120 g），低于阈值时补货清单就自然出来了。
