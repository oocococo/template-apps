# 健身管家

健身场馆的订单、客户、招生官、门店、课程和提成管理工具。支持按比例或固定金额计算提成、二级分成、结算状态、报表、CSV 导入、表格及文档导出和 JSON 备份恢复。

应用使用 Tiana 身份和 SQLite。获平台授权访问同一应用的成员共享其业务数据；招生官档案不会自动授予平台访问权限。不同安装使用各自的资源。记录编辑使用版本检查，遇到冲突请重新读取后再保存。

## 安装与构建

1. 创建或按要求核实 SQLite 与 Git 实例，按 `metadata.json` 将 `source.json` 中的变量替换为相应实例 ID。
2. 对 SQLite 默认分支先执行 `schema.sql`，再执行 `seed.sql`；后者仅初始化课程与提成设置。
3. 执行 `npm ci --ignore-scripts`，提交并核实源码版本后运行 `npm run build -- <完整源码提交号>`。构建输出 `dist/assets/app.js`、`dist/assets/app.css` 和 `dist/icon.png`，入口为 `assets/app.js`。
4. 使用绑定的 Tiana Web 项目预览或发布，并验证运行时身份、数据库读写及刷新行为。

导入 CSV 使用页面提供的列顺序和模板；重复电话会跳过。备份可设置密码，恢复会在确认后覆盖本应用数据。恢复前请保留当前备份。
