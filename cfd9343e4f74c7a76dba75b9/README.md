# 高数练习卡片

按题型、函数和变量组卷，练习积分与导数，查看解析和分类统计。练习统计保存在 Tiana 数据库，公式字体保存在当前应用的文件目录；当前题目和未提交答案不跨刷新保存。

## 初始化和构建

按 metadata.json 为本应用创建 SQLite 和 Git 实例，填写 source.json，执行 schema.sql。安装依赖 `npm ci`，提交并推送源码后执行 `npm run build -- <完整源码提交号>`，输出入口为 assets/app.js。构建参数可经 CALCULUS_BINDINGS 指定独立绑定文件，不修改参数化源码。

预置字体在 template-files/fonts/，metadata 的 file_seeds 声明使市场安装器自动安装到本应用的 template-assets/fonts/。本地开发先创建 Web 获得 ID，再经 Tiana file put 准备相同目录，随后预览；直接安装和保留源码均自动准备字体。应用只使用平台提供的文件 API，不依赖作者文件链接。

统计更新采用版本检查，防止另一页面的旧统计覆盖新数据。保存失败时保留当前页的统计并提供核对入口；版本冲突时明确提示，刷新后读取云端版本。保存完成后再关闭或刷新。分析页的清空仅重置本应用的练习统计。

市场预览是自包含的示例，数据保留在当前页面，不连接数据库或文件服务。平台图标继续随 Web 包；程序与样式随 Web 发布，字体不进入 Web 包。
