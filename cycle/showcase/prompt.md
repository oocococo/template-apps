请用 Tiana 的 cycle（周期）模板制作一款记录定期事项的应用。先执行 `tiana web init-template cycle --dir my-cycle` 拉取完整源码，按 metadata.json 创建并绑定本次应用的 SQLite、Git 和 Web，初始化数据库后构建发布。

保留以手机为主的自适应界面、自定义事件名称与间隔天数、到期提醒、多标签分类、名称搜索、归档恢复，以及精确到分钟的多次完成记录、耗时、备注和照片。点击事件进入历史列表，用悬浮按钮添加记录；支持最近七天、本周、整月、全年与自定义日期范围的次数变化统计，年视图按月汇总，其余按天统计。

可以继续调整配色、图标和初始示例。提醒在应用内展示，不包含关闭网页后的系统推送。
