# 一页的内容与数据

## 使用与冷启动

首次进入提供空白一页、随手记、会议记录和灵感便笺四个入口。选择模板才创建笔记，内容可直接修改。标题和正文采用无框编辑，细线与光标提示正在书写；分类使用自定义下拉。保留淡紫色列表、置顶标记、移动端列表返回。

## 自动保存

输入停止 600 毫秒后提交最新内容。同一编辑会话按顺序保存，切换笔记、分类视图或搜索前等待当前保存。保存中继续输入时，当前请求完成后再写最新内容；只有被确认的内容显示已保存。

写入响应丢失时按笔记 ID 独立读取，内容一致则确认完成；无法确认或内容不同则暂停自动保存，保留当前草稿并显示「检查并保存」。用户点击后先读当前记录再保存当前内容，不自动重放未知写入。页面关闭时对未确认修改给出浏览器离开提示，草稿不写入浏览器持久存储。

## 存储与查询

`notebook_notes` 保存标题、正文、分类、置顶和更新时间，`(app_id, id)` 主键用于定点读写；`(app_id, pinned DESC, updated DESC, id)` 索引用于当前应用的置顶优先列表。每页 50 篇，用户点「加载更多」读取下一页。全文搜索在当前应用及所选分类范围内匹配标题或正文，搜索词通过参数绑定，支持中文和引号。

多窗口同时编辑按最后一次成功保存覆盖，不展示实时协作承诺。
