# 内容与交互说明

模板用柔和的陶色、乳白色和绿色呈现陪伴感。首屏同时展示当前阶段、已完成数量、两人共同的本周清单、旅程刻度、鼓励文案和留言入口。任务行提供完成与评论入口；阶段、周数和爸爸/妈妈筛选在同一屏操作。新应用首次打开时展示本周任务建议，留言区邀请双方写下第一句话。

侧边栏的四个入口对应独立视图：旅程总览呈现阶段与本周进度；每周清单集中提供阶段、周数和角色筛选；心情日记展示共同留言与记录入口；小小奖励只根据实际完成记录点亮纪念。切换视图后当前阶段、周数、任务完成状态和留言保持一致。

`journey_settings` 保存当前阶段、当前周、开始日期和可修改的双方称呼；`journey_progress` 按阶段与周保存模板任务的完成时间；`journey_comments` 保存留言及关联任务。完成数量从本周任务记录计算，不单独写一个计数。`week-plans.json` 提供备孕 1–12 周、孕期 1–40 周各自的主题、陪伴语和任务；相邻周有不同内容。修改任务内容时保持稳定的 `phase-week-index` 任务 ID，或同步迁移已有完成记录。

模板中的清单是生活协作提示。用户需要医学建议、检查或用药安排时，核对可靠来源或使用其医生给出的方案，再修改对应内容。
