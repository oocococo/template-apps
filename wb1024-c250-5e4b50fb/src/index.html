📖 使用说明 / 给别人怎么用
  • 第一步：在「① 科目与折算设置」里改成本地区方案 —— 科目名、折前满分、折算系数都能改，也支持增删科目。不确定就先用「惠州中考」预设再微调。
  • 第二步：在「② 录入考试成绩」填考试名称 + 各科折后分（满分口径见输入框上方小字），点添加。没考的科目留空即可。
  • 第三步：顶部「折后 / 折前」一键切换全看板口径；「各科对比」任选两次考试看每一科涨跌。
  • 数据存在哪：自动保存在本机浏览器（localStorage），不上传任何服务器，断网也能用。
  • 换电脑 / 发给别人：点「导出数据」得到 JSON 文件，在另一台机器的看板里点「导入数据」即可完整恢复（科目、成绩、目标都在内）。
  • 给别人用：直接把整个 HTML 文件发给他，双击用浏览器打开即可 —— 无依赖、无需联网、无需安装。他自己录入的成绩只存在他自己电脑上。
  • 存档：点「打印」可输出 PDF（自动展开全部卡片、隐藏按钮）。
