# 素材手册

打开一张图片，下载一份 PDF，为每份资料留下阅读笔记。手机和桌面使用相同的资料与笔记。
同一应用的访问者共享笔记；同时编辑时会提示重新读取，避免直接覆盖另一份修改。

笔记及资料相对路径保存在 Tiana SQLite，图片与附件保存在当前应用的文件目录。
应用使用运行时身份连接数据库和文件服务，源码不包含访问凭据。内置素材为可公开的合成示例。

## 构建与初始化

1. 创建本次应用的 SQLite、Git 和 Web，Web 入口使用 `assets/app.js`。
2. 按 `metadata.json` 替换 `source.json` 的资源变量。作者调试可通过
   `MATERIAL_HANDBOOK_BINDINGS` 指向工程外、包含实际绑定的 JSON；不在模板中提交作者绑定。
3. 先执行 `schema.sql`，再执行 `seed.sql`。初始数据幂等，保留已经编辑的笔记。
4. 本地开发先将 `template-files/` 中的两份素材上传至
   `<本次 Web ID>/template-assets/` 下相同的相对路径，再启动预览。
5. 执行 `npm ci` 和 `npm run build -- <源码提交>`，按构建输出绑定资源并发布 `dist/`。

市场安装由平台为每份应用准备独立素材。`tiana web init-template 721db993c952755ac056c2b7 --dir PROJECT`
只下载源码；Agent 完成变量、数据库和开发素材准备。

图片通过文件服务读取，资料路径没有作者 URL。页眉的小书标在构建时内嵌到 JavaScript，
平台图标随 Web 制品分发。应用不在首次打开时重新上传、补齐或覆盖已安装的文件。

## 阅读和笔记

选择图片或指南，编辑笔记后点击“保存笔记”。重新读取只读取远端数据，保留本页尚未保存的草稿。
保存结果不明时先重新读取核对；应用不会自动重发写入。页面刷新后从数据库读取已保存内容。

`npm run preview:build` 生成自包含市场示例。示例中的保存和“恢复示例”只影响当前页面。
