# 大兜力量池 产品规格

## 定位

单人使用的自律打卡与自我奖励应用：每天写一篇日记，把完成的事情换成金币，攒到目标后兑换给自己的小奖励。使用 Tiana 账号登录，业务数据保存在本应用绑定的 SQLite 中，照片保存在本应用文件存储中，不提供多人、分享或外部服务。

## 页面框架

- 顶部：标题「大兜力量池✨」（22px）与右侧小字「把每一天都攒成一束光」。
- 底部固定导航三栏：📓 日记、📚 任务、🎁 兑换；当前项文字为 #F28B66，其余 #888，背景 #F9F5F0 半透明并模糊。
- 哈希路由 `#/diary`、`#/task`、`#/exchange`，根路径进入日记；切换页面时淡出淡入（opacity 0.18s，先出后入）。刷新或直接打开深链接停留在对应页面。
- 全局底色 #F9F5F0，主强调色 #F28B66→#FF6B35 渐变，水色 #A8D8E8→#5DA9C7，正文 #333/#555/#888；手机与桌面共用同一流式布局，最大宽度随视口铺开。
- 数据读取完成前只显示页面底色；读取失败显示提示文字。

## 日记页

- 标题「日记本」，副标题「写下今天，完成的事会自己变成金币」。
- 横线信纸卡片：左侧竖线与装饰贴纸（✨⭐🌸🍡🦋💫）、日期「YYYY年M月D日 · 周X」、右上角「+N 金币」实时预估。
- 编辑状态：
  - 心情五选一（🤩超兴奋、😊开心、😐平静、😮‍💨有点累、😭低落），默认开心；心情决定正文颜色、字重和轻微倾斜。
  - 正文为手写风可编辑区域（ZCOOL XiaoWei，回退楷体），占位「今天发生了什么呢……」。
  - 「完成任务（点加减数量）」按分类列出任务胶囊，「−」「+」调整数量，选中后显示 ×数量与浅橙底。
  - 「📷 添加照片贴纸」可多选图片，贴纸以随机角度的圆角方块显示，可单独移除；提示「照片会自动变成可爱贴画，贴在日记里」。图片在浏览器内按最长边 600px 重新编码后保存。
  - 主按钮「保存日记」；已有日记时另有删除入口（确认后删除）。
- 已保存状态：照片贴纸、带胶带装饰并按心情着色的正文便签、心情胶囊、已完成任务胶囊（✓ 名称 ×数量 +金币），按钮「编辑今天的日记」。
- 金币规则：
  - 预估 = Σ（当前任务金币 × 数量）。
  - 保存时把每项任务名称、金币和数量写入快照，此后修改或删除任务不影响已保存日记。
  - 同一天再次保存，总金币按（新所得 − 原所得）调整，可能因此低于 0。
  - 删除日记扣回该日所得，总金币最低为 0。

## 来时路月历

- 标题「来时路」与说明「小水瓶 = 当天任务进度」。
- 月历：‹ 上一月、「YYYY年M月」、今天、下一月 ›；周日起始。日期按两位数显示，选中日期为 #F28B66 实心圆角方块，今天为浅底。
- 有日记的日期下方显示小水瓶，水位 = min(1, 当日金币 / 30)，水位变化 0.5s 过渡。点击日期切换到该日的日记（无日记时进入编辑）。

## 任务页

- 标题「爽文女主养成计划」，副标题「分类养成 · 规则仅对新日记生效」，右上角圆形「+」新增。
- 分类卡片：学习篇（#FFE7CF）、健身篇（#D7E8C7）、技能篇（#E5E1EE）、自媒体篇（#FCEFB8），自定义分类为 #F3EDE5；无任务的分类隐藏。卡头显示分类名、项数和「+ 添加」，任务行显示名称、示例标记、+金币、编辑、删除。
- 底部小提示卡说明金币快照规则。
- 新增/编辑弹层（手机为底部弹出，桌面居中）：任务名称（≤20 字）、金币数（0–999）、分类（四个固定分类或「+ 其他篇」输入自定义名称，≤10 字）。名称为空时不保存。
- 删除任务需确认，提示历史已发放金币不变。
- 示例任务：一节网课 +2、一套卷子 +5、读书1小时 +3（学习篇）。示例任务缺失时，下次打开应用会在列表末尾补回。

## 兑换页

- 标题「解锁犒赏」，副标题「把努力攒起来，换你想要的小奖励 · 长按拖动调整顺序」。
- SVG 蓄水瓶：显示「当前总金币」与鼓励语，右上「本瓶刻度」。刻度取排序第一的目标所需金币，没有目标时为 200；水位 = max(4%, 总金币 / 刻度)，上限 100%。总金币为 0 时显示「蓄水瓶空空如也，去写日记来灌水吧～」。
- 兑换目标列表：未完成目标按用户顺序在前，第一个标记「本期」「· 当前正在攒」并显示「已攒 X / 需要」及百分比，其余显示「还差 N 金币」；已完成目标排在后面，按兑换时间倒序，显示「已完成」「已达成」、绿色满进度条。
- 「+ 自定义目标」弹层：目标名称（≤20 字）、所需金币（1–9999，默认 20）。
- 兑换：金币不足时按钮置灰；足够时确认后扣除金币并标记完成。删除目标需确认。
- 未完成目标可拖动排序，顺序保存到数据库。

## 数据

| 表 | 内容 |
| --- | --- |
| pool_wallet | 单行总金币 |
| pool_tasks | 任务名称、金币、分类、是否示例、排序位置 |
| pool_diaries | 每日一篇：正文、心情、完成任务、数量、金币快照、所得金币、创建与更新时间 |
| pool_photos | 日记照片文件相对路径及顺序 |
| pool_rewards | 兑换目标、所需金币、是否完成、排序、创建与兑换时间 |

保存日记、删除日记和兑换在单个事务中同时更新金币与记录。兑换在数据库中再次核对目标未完成且金币足够。写入失败时提示并重新读取数据，保留当前编辑内容。正文只保存编辑器生成的 span/br/div 结构。

## 验收

- 新安装：空日记、总金币 0、三个示例任务。
- 写日记（含心情、正文、两项任务及数量、两张照片）并保存，金币与月历水瓶更新；刷新后内容、照片和金币保持。
- 修改同一天的任务数量后再保存，总金币按差额变化；删除日记扣回金币且不低于 0。
- 新增自定义分类任务、编辑、删除；删除示例任务后重新打开会补回。
- 新增两个目标，蓄水瓶刻度跟随第一个目标；兑换后金币扣除、目标移到已完成；拖动排序后刷新保持。
- 桌面 1440×900 与手机 390×844 布局、弹层位置和过渡动画与本规格一致。
