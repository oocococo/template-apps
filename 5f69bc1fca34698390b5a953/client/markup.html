📄 导入 / 导出说明
· 支持格式：JSON / CSV / XLSX（Excel）
· 导出文件由浏览器下载到默认下载目录
· 记录数组和 CSV / XLSX 导入会追加记录；备份快照恢复会覆盖账本，请先备份
· CSV / XLSX 需含表头：类型、分类、金额、日期（备注、来源可选）；类型填「收入/支出」，金额填数字，日期格式 2026-08-20
· JSON 支持记录数组或备份快照两种结构

打工人小账本

记一笔 30 秒，月底自动算清钱到底花在哪。

  • 记账分类点一下、金额一填就存。支出分「固定 / 弹性」，房租水电和奶茶外卖分开算。
  • 统计支出构成排行 + 固定 vs 弹性占比，记账区间自己定，看清哪些钱躲不掉。
  • 查询按金额或备注搜记录，也能按月看日历格，哪天花了多少一目了然。
  • 搬账支持 JSON / CSV / Excel 导入导出，从支付宝、微信账单整理出来的表也能直接导进来。

已经给你载入一份示例账本，可以直接点着看。账本数据保存在此应用的云端数据库。
