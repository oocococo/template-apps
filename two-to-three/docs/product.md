# 两个人，三个人

当前界面包含我们的旅程、营养补剂、待产包和心情日记四个入口；补剂与待产包在确认怀孕后显示。备孕与孕期的阶段标签仅用于浏览，切换阶段不会改写真实状态。备孕清单包含12周，孕期包含40周，任务ID沿用 phase-week-index。支持爸爸/妈妈筛选、完成与撤销、任务留言和已完成回顾。

确认怀孕时填写末次月经第一天，应用按日期估算孕周、阶段和预产期，并自动选择当前周；可修改日期或回到备孕模式。营养补剂分备孕、孕早期、中期、晚期，展示原应用的静态参考指南。待产包按入院当天、月子中心、在家请月嫂三个场景展示分类清单与进度，每个场景独立保存勾选。共同日记和称呼可编辑，手机布局保留紧凑的状态卡、指标行与可滚动标签。

SQLite 保存 journey_settings、journey_progress、journey_comments、journey_pregnancy 和 journey_checklist。种子只创建 main 的默认设置，起始时间为安装当天；不导入作者留言、末次月经、完成记录或物品勾选。成员共享同一份旅程，每次安装创建独立数据库。待产包主键为(id, scene)，避免多场景记录相互覆盖。修改任务内容时保留稳定ID，或迁移已有记录。

指南、孕周及预产期仅用于生活准备和参考；具体补充、检查及诊疗遵医嘱。没有系统推送或多人实时同步。运行 npm test 可验证不同待产场景的保存互不覆盖。
