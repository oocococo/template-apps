整体转 x / y / z 只换视角、不计步数（x 随 R、y 随 U、z 随 F），等价于把整个魔方在手心里换了个方向； 连点两次可合成 180°。整转之后，后面写的方向记号都按新握持算（y 之后的 R = 原来的 B）。侧层 S 是「绕视线方向」的那片中层，屏幕上没有对应的滑动方向，只能点 —— 想用手势做就先按一下 y，视角转过去后它就会变成某条上的圆圈。
三阶魔方公式记号（Singmaster）
U上层 Up
D下层 Down
L左层 Left
R右层 Right
F前层 Front
B后层 Back
M中层（随 L）
E赤道层（随 D）
S侧层（随 F）
x整体随 R
y整体随 U
z整体随 F
Rw宽转：R + M′
单个字母 = 站在该面外侧看顺时针转 90°； 带 ′（或 '）= 逆时针；带 2 = 180°（无论正反都一样，记 1 步）。 R2′ 与 R′2 写法都支持。 中间层 M / E / S 的方向分别跟随 L / D / F；整体转 x / y / z 只改变视角、不计步数， 但会改变握持 —— 之后的 R / U / F 都以新握持为准（这就是公式里「y R」的含义）。
宽转 Rw = 右层连带中间层一起转 = R + M′， 六个面都有（Rw Uw Fw Lw Dw Bw），各记 1 步。小写 r/u/f/l/d/b 也表宽转（r=Rw）， 即裸小写面字母 = 宽转、单层请写大写；也可显式写带 w 的形式。
重复 / 括号记法：(R U R′ U′)3 = 括号内重复 3 遍（括号后紧跟的数字就是遍数， (R U)2 = 两遍）；x3 = 前一个记号重复 3 次。注意记号后面的 2 仍是 180° 后缀 （R2 是转 180°，不是「R 做两遍」），再后面的数字才当重复次数（任意位数、上限 99， 如 R23 = R2 重复 3 次）。括号须配对：多余的 ) 会报「无法识别」； 漏写 ( 不报错，内容按顺序执行；前面没有记号的孤立数字（3 R U 里的 3）同样报「无法识别」。
整体转 x / y / z 与侧层 S 在屏幕上的转动方向「看不出来」，所以走按钮栏的「整转」面板， 或直接敲键盘 X / Y / Z / S（Shift 反向）。M / E / S 三个中层里， M 和 E 就在四条控制条的圆圈上，S 要等视角转过去才会变成某个圆圈。
例：R U R′ U′（性感手法，连做 6 次回到原状）； R U R′ U′ R′ F R2 U′ R′ U′ R U R′ F′（T-perm，交换上层的右前角与右后角、 上层的左棱与右棱，两块都不翻色）。 两段都可以直接粘进上面的输入框执行。

魔方 / 空白 拖动 = 转视角
上 / 下条 左右滑 = 上层 / 下层　·　左 / 右条 上下滑 = 左层 / 右层
条分两半 圆圈两边各标着该方向的记号，点一下就转（左半 = 往左滑那一手，右半 = 往右滑那一手； 竖条则是上半 / 下半），拖动照旧
条中圆圈 点一下就转中间层，四个圆圈互不相同：上条 = M、下条 = M′、 左条 = E、右条 = E′（中心标的就是点出来的那一手）；按住出箭头， 沿箭头滑也能转中间层，箭头上的记号即滑过去的那一手（一次按压只转一次，再转需抬手重按）
四角按钮 上排转背向屏幕那一层 B / B′　·　下排转朝着屏幕那一层 F / F′ （左下→ 右下←），可长按连转；视角转过去后标签会换成实际的面名
连点两次 同一个控件点两下 = 该层 180°，走法记录自动写成 X2（点第三下变 X′）； 慢慢点两下仍如实记为两步
整转 点按钮栏的「整转」展开 x x′ x2　y y′ y2　z z′ z2 与侧层 S S′ S2（右上角 × 或点魔方可收起）。 整体转只换视角、不计步；S 是绕视线方向的那片中层，屏幕上没有滑动方向，只能点 （想用手势做，先按一下 y，转过去后它就变成某条上的圆圈）
记号 控件上标的是标准 Singmaster 记号（U D L R F B + M E S，逆转加 ′）， 顶栏「最近」显示刚做的那一步。视角一转，标签会跟着变 —— 因为转的是「当前视角下那一层」， 比如转到侧面后，上条转的可能是 R 面
键盘 U D L R F B + M E S + 整体转 x y z，Shift 反向。记号按握持解释： 整转 x / y / z 之后再敲 R，转的是新握持下的右面（和公式里写的一样 —— y 之后的 R 其实就是原来的 B 面）； 拖动屏幕换视角不会改变记号含义。控制条 / 四角则始终是「屏幕上那一层」
公式输入 支持 U D L R F B M E S、整体转 x y z、宽转 Rw Uw Fw Lw Dw Bw， 可带 2（180°）与 ′（逆转，R2′ 与 R′2 都认）。小写 r/u/f/l/d/b 即宽转（r=Rw），单层请写大写； 空格、中英文逗号 / 顿号 / 分号、以及 / | . - + 都作分隔符，点「执行」按公式转动。整转只换视角与握持、不计步数； 宽转 = 两层一起转（Rw 就是 R + M′），算 1 步；只有六个面层有宽转写法 （Rw…Bw 或小写 r/u/f/l/d/b），中层 Mw / Ew / Sw 与全角括号 （） 都不认、会报「无法识别」， 重复 / 括号记法请用半角括号：(R U R′ U′)3 = 括号内重复 3 遍，记号后的数字（任意位数、上限 99）为重复次数， 如 R23 = R2 重复 3 次；多余的 ) 报「无法识别」，漏写 ( 不报错。 另注意公式输入里小写 = 宽转，与键盘是两套语义：键盘敲 r 和 R 都转 R（Shift 才反向）
计时 自动计时：走第一步自动开始、完全复原自动停止，期间不能暂停、不能手动复位（只有「打乱 / 复原」会清零） · 手动计时：全部由「开始 / 暂停 / 计时复位」控制，不会自动起停
公式记录 「打乱」显示打乱序列（不计入步数），「走法」记录你的每一步（整转 x/y/z 也记、但不计步）， 都可复制；两个「清空」各自清对应记录，并同时清空剪贴板（比赛防作弊）
翻译 白话翻译区常驻页面（在「打乱 / 走法」两行下方），会实时显示你每一步走法的白话； 也可点「公式输入框 / 打乱序列」临时看对应翻译，但你一走子会立刻切回走法翻译
面标记 若浏览器仍把颜色压暗，开启后靠形状分辨：○上 ✚下 ●前 ■后 ◆右 ▲左
白面色阶 10 档，从纯白到近黑。哪块在你屏幕上最白就点哪块。
注意：最亮的往往不是最深那档 —— 浏览器只压暗浅色，越过阈值后颜色原样保留， 再深只会更暗。所以往右试到开始变暗的那一档就是最佳值
