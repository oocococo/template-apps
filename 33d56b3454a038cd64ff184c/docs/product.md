# 交互与同步说明

界面由深色窄侧栏、白色项目顶栏、浅色点阵画布、左侧悬浮工具栏和按需出现的便签配色面板组成。空画布展示三个可点击的起步方向和空白便签入口；顶部也可直接新建便签。可用工具：选择/拖拽、添加便签、画笔、连线和平移；滚轮或按钮缩放，并可一键适配已有内容。新便签直接进入编辑，双击便签再次编辑，双击空白处也能创建；选中后可换色或删除。分享按钮打开含当前地址的弹窗，便于选中复制。

侧栏的概览入口展示当前白板的便签、连线和画笔数量，以及最近的便签；点击便签可回到画布并定位该元素。画布入口返回编辑界面，问号入口打开完整操作说明。概览内容直接由当前白板数据计算。

`board_notes` 按白板 ID 存每张便签的位置、文本和颜色；`board_links` 存元素间连线；`board_strokes` 存画笔路径；`board_profiles` 存各客户端可修改的显示名称。查询均限定到当前 `board_id`，不同元素的保存互不覆盖。客户端每 1.5 秒读取当前白板，在拖拽或编辑时暂缓刷新；同一元素的同时修改按最后提交的结果显示。当前模板演示一个共享白板 `main`，可复制为不同白板 ID 来创建其他空间。

桌面快捷键包括 V/N/P/L/H、空格拖动画布、Enter 编辑选中便签、Delete 删除和 Escape 取消选择。
