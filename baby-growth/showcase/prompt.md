使用 Tiana 的 baby-growth 模板，为我制作「宝贝成长记」网页应用。先运行 `tiana web list-template --json` 核对模板，再用 `tiana web init-template baby-growth --dir baby-growth --json` 拉取完整源码。按 metadata.json 创建并填写本次 SQLite 和 Git 绑定，依次执行 schema.sql 和 seed.sql，然后构建和发布到 Tiana Web。

应用以手机使用为主，保留奶油色、鼠尾草绿和柔和的彩色图标，也适配桌面。首页展示宝宝昵称、出生日期和月龄，提供身高体重、辅食日历、宝宝账本、每日事项、疫苗记录、牙齿发育和成长里程碑七个入口，以及当天待办。测量曲线和生长档位使用卫健委 WS/T 423—2022 的性别、月龄参考表；辅食支持周/月日历及过敏记录；账本支持人民币收支、分类、自定义图标和区间统计；牙图可逐颗记录 20 颗乳牙的萌出日期；里程碑支持四个分类及自定义事件。所有个人记录保存到本次数据库，试玩示例不导入用户应用。
