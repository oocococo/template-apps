# 宝贝成长记

为刚有宝宝的家庭准备的成长记录应用，优先适配手机，也支持桌面浏览。使用 Tiana Web 托管，Tiana SQLite 保存数据，一个应用记录一位宝宝。浏览器后退和手机侧滑返回由哈希路由支持。

首页展示宝宝昵称、出生日期、当前月龄、七个功能入口与当天待办。

- 身高体重：多条测量记录、编辑删除、变化曲线，以及卫健委 WS/T 423—2022 的性别 / 月龄档位和 P3–P97 参考范围。
- 辅食日历：周 / 月视图、按日编辑早餐午餐晚餐和水果、食物过敏与已排除过敏记录。
- 宝宝账本：人民币收支、一级分类、24 个可选图标、分类增改删、日周月年 / 自定义区间统计、分类排行与支出环比。金额以整数分存储，删除分类后历史账目保留原名称和图标。
- 每日事项：任意日期的事项、完成状态、可展开月历，以及以今天为起点的未来三日安排。
- 疫苗记录：自定义疫苗和剂次，默认待接种，支持实际接种日期、状态、备注与编辑删除。
- 牙齿发育：20 颗乳牙的可点击牙图、FDI 编号、萌出日期与备注、时间顺序记录和萌出月龄参考。
- 成长里程碑：大运动、精细运动、语言、社交认知四类预设事件；自定义事件可增改删，事件可记录达成日期和备注。

## 安装与构建

1. 创建 SQLite、Git 实例。按 `metadata.json` 替换 `source.json` 的两个占位符，使用创建回执中的完整 ID。
2. 在目标数据库先执行 `schema.sql`，再执行 `seed.sql`。种子仅包含分类和里程碑预设，不包含宝宝个人记录，可重复执行。
3. 执行 `npm ci`，提交源码到自己的 Tiana Git，确认远端提交后运行 `npm run build -- <完整提交号>`。
4. 创建 Web 时设置入口 `assets/app.js`，绑定目标数据库和 Git。发布 `dist` 目录；运行时通过 `window.tiana.connection()`、`window.tiana.auth` 和 `window.tiana.appId` 提供连接与应用身份。无需在产物中替换实例 ID。
5. 第一次打开应用时填写宝宝档案。

`npm run dev` 启动界面开发服务。真实数据库读写请通过已登录的 `tiana web serve <Web ID> --dir dist --port 4186` 预览，或使用正式托管入口。

## 验证与试玩

`npm test` 验证月龄、金额精度、统计区间及标准表的档位边界。`npm run test:showcase` 在 `sandbox="allow-scripts"` iframe 中验证试玩的记录增改删、取消、页面切换、恢复示例和手机布局；首次使用 Playwright 时先执行 `npx playwright install chromium`。

`npm run showcase` 从同一套组件、样式和合成数据构建 `showcase/preview.html`。试玩数据只保存在内存，点击“恢复示例”重置；文件自包含且不超过 500 KB。源码构建默认连接 Tiana，只有单独的试玩构建使用示例数据。

## 数据与使用范围

`baby_records` 按记录类型保存带主键、日期和 JSON 内容的记录，`kind/day` 索引用于类型和日期检索；每次编辑独立保存一条记录。多个页面复用内存数据，刷新后从数据库读取。

适合一个家庭通过同一应用记录一位宝宝，不包含多宝宝切换、家庭成员权限管理、自动提醒推送或医疗诊断。共享应用的成员共用同一份手记；同时编辑同一条记录时，以后保存的内容为准。

生长档位、取表方式和适用范围见 [生长参考说明](docs/growth-reference.md)。彩色图标来源与许可见 [图标来源](docs/icons.md)。
