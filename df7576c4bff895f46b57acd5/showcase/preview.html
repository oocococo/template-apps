使用说明 · 帆软侧怎么配 · 报错怎么查

帆软后台要做的配置

  1. 安装「后台单点登录插件」（帆软市场可下载），重启工程。
  2. 超管进平台：管理系统 → 系统管理 → 集成后台单点登录。
  3. 选择「用户名加密」方案，点「生成 RSA Key」 并保存 —— 插件只支持它自己生成的 Key，不能自定义。
  4. 把页面上显示的 Public Key 整段复制到本工具左侧。
  5. 如果开启了 「ssoToken 超时设置」，本工具的明文格式要选「用户名 + 时间戳 JSON」。

两种明文格式怎么选（最稳的办法）

插件未开超时明文 = zhangsan 插件开了超时明文 = {"username":"zhangsan","issueTime":1759225445123}

拿不准就用帆软后台自带的「解密测试」验证：先按一种模式生成，把密文贴进帆软那个「解密测试」框点解密 —— 能解出用户名（或用户名+时间戳），说明模式选对了；解出来是乱码或报错，就换另一种模式。

加密算法（与帆软官方 Java 示例完全一致）

公钥格式X.509 / SubjectPublicKeyInfo（DER）的 Base64 算法RSA / ECB / PKCS1Padding 明文编码UTF-8 分块长度245 字节 / 块（2048 位密钥下 PKCS1 上限），逐块加密后拼接 输出整体 Base64 → 再做 URL 编码 参数名ssoToken 
http://ip:port/webroot/decision?ssoToken=<加密后再URL编码的内容>

常见报错

  • 登录超时，请重新登录 —— token 过期了。开超时模式时，时间戳必须在「登录超时时间」范围内，所以要在用户点击的那一刻实时生成，不能提前算好存起来。
  • Decryption error / 解密失败 —— 多半是公钥和帆软当前配置的不是同一对（改过 Key 或重新生成过）。重新复制一次 Public Key。
  • 用户名不存在 —— 帆软平台里没有这个账号，或者开启单点登录后普通登录入口被关了。
  • cptx 模板报 Decryption error —— 插件 V1.1.1 之前对新计算引擎的 cptx 模板不兼容，把 cptx 嵌进 frm，或先跳 cpt 再转 cptx。

在 OA 里怎么用

免登链接是一次性、带时效的，正确做法是把加密逻辑放到 OA 服务端： 用户点菜单 → OA 后端用公钥加密该用户账号 → 302 跳转到帆软。

OA 后端拿不到 Java 环境时，可以照抄本工具的算法（RSA/ECB/PKCS1Padding + Base64 + URLEncode）， 本工具「批量生成」页签就是给运维临时出链接、对账号用的。

安全提醒：公钥可以随便存，但明文模式生成的 token 是固定值，谁拿到链接谁就能登录。 正式环境建议开启 ssoToken 超时设置，并让 OA 在跳转瞬间实时生成。

技术底座

没有用任何加密库和表格库。两套内核都是手写的，并且做了双向交叉验证。

RSA 内核
自己解 DER 拿模数和指数，自己实现 PKCS#1 v1.5 填充和 BigInt 模幂，245 字节分块。与 OpenSSL 双向交叉：本工具加密、OpenSSL 解密，以及反过来，全部还原正确。
表格内核
手工拼 OOXML、手工写 ZIP（含 CRC32 与中央目录），读的时候走浏览器原生 DecompressionStream。与 SheetJS 双向交叉，中文、特殊字符、长文本都一致。
测试
支持在页面内运行加密与解密自检。
隐私
加密在浏览器中完成。安装应用的配置保存在应用数据库；请谨慎保管生成的登录链接。
