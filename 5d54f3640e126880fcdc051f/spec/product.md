# 灵签易占

以梅花易数及传统卦象资料供文化娱乐。四个标签依次为起卦、卦库、历法、卦历。所问之事可为空；问题识别影响取象与应期，不改变同一卦和月令的吉凶。每日和时间按本地日期与时辰确定性起卦；数字需两个正整数；铜钱以三枚钱掷六次，自初爻向上。保留卦图、结论、条件解释和起卦依据。卦库提供 64 卦搜索、详情和以选中卦起卦；历法显示当日干支、时辰及节气等资料；卦历保存结果摘要与可选批注，并支持删除。

采用原有朱砂、暖纸色、书卷式布局，桌面结果为本卦与变卦双栏，窄容器单栏；保留四页导航、推演动画与控件状态。全部规则和内容在浏览器计算；卦历写入本应用绑定的 SQLite。授权访问同一安装的用户共享其卦历，刷新或再次进入读取最新数据；不同安装隔离。新增使用唯一 ID，删除按 ID 操作；冲突或未知写入结果应回读，不自动重放。来源资料的文字由 AI 制作，仅供娱乐，无实际预测功能，不作为医疗、法律、财务等决策依据。
