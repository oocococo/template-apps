# 字体许可

本应用使用以下字体，均来自 Google Fonts 仓库，以 SIL Open Font License 1.1 发布：

- Liu Jian Mao Cao：`liujianmaocao-OFL.txt`，来源 https://github.com/google/fonts/tree/main/ofl/liujianmaocao
- Ma Shan Zheng：`mashanzheng-OFL.txt`，来源 https://github.com/google/fonts/tree/main/ofl/mashanzheng
- Zhi Mang Xing：`zhimangxing-OFL.txt`，来源 https://github.com/google/fonts/tree/main/ofl/zhimangxing

文件由上游 Regular TTF 转换为 WOFF，以便应用加载。许可和版权声明见对应 OFL 文件。
