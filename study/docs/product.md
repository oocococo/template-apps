# 心屿 · 个人专注与建岛

本工程从作者指定应用的线上 JavaScript、HTML 标记和 CSS 恢复整理，SDK 使用公开依赖包。未使用旧模板的任务清单逻辑。原始发布版中的无效统计刷新调用和残缺的无引用动画片段已清理。

## 使用流程

在今日页点击开始专注，选择学习、工作、阅读、运动、其他标签，输入标题，选择动工项目和时长。暂停后可继续；刷新会从浏览器保存的状态恢复。终止前有确认，放弃后在对应街区留下工地。完成一轮后自动保存时间记录并落成建筑，刷新今日分钟、本周足迹、岛屿和复盘。

岛屿按标签分街区，点击建筑可查看落成时间、标签、标题和分钟数。金币等于累计专注分钟减去已解锁花费，可解锁特殊建筑；里程碑根据累计分钟、建筑数和连续天数达成。

## 数据与边界

SQLite 保存 study_sessions（含 title/tag 和兼容字段 task_id）、study_profile、island_buildings、island_unlocks。应用成员共用同一份记录，安装默认空库，不复制个人记录。每次安装使用自己的数据库；记录沿用 main 工作区。浏览器计时状态和建筑选择按运行时应用身份隔离，不同步至其他浏览器。

计时以目标时间与当前时间差计算；刷新或重新打开时恢复或结算已到期的一轮。后台时浏览器可能延迟执行，关闭页面后无系统通知。不能作为精确后台计时或多端同时计时工具，不包含任务清单、锁机或实时协作。

## 模板验证

使用独立数据库验证标签/标题专注、暂停继续、刷新恢复、完成记录及建筑详情、终止确认、复盘和移动端。预览使用合成数据和页面内状态，不连接数据库。运行 npm test 验证完成专注后的保存、统计刷新和成功提示。
