# 心屿的页面与数据

今日、我的岛屿、复盘三个视图共用同一份应用数据。今日提供新建任务、完成/撤销完成和状态筛选；计时器可选择任务与建筑，支持25/30/45/60分钟，运行中锁定选择，暂停可继续。专注完成写入 study_sessions 并关联 task_id，任务显示累计专注/预计时长；任务是否完成仍由用户勾选。

每轮完成在 island_buildings 留下一座建筑，按学科分街区展示；运行中重置留下 ruined 工地，不奖励分钟。金币为成功专注总分钟减去 island_unlocks 解锁花费，支持基础、金币与里程碑建筑。暂停不算放弃，暂停后重置也不会留下工地。建筑选择保存在浏览器本地，其他记录存 SQLite。

study_tasks 保存任务，study_sessions 保存专注和任务关联，study_profile 保存称呼；island_buildings 保存建筑与工地，island_unlocks 保存解锁花费。workspace_id 固定为 main，每个应用成员共用同一份记录，建议个人使用。安装只执行 schema，不附带个人记录或虚构学习时长；首次显示建议任务，用户主动加入才入库。

复盘以会话统计最近7天、此前7天、全部学科投入和连续自然日。计时器每秒递减，关闭页面不会续计，后台节流可能影响准确性；不支持后台计时恢复、锁机与系统通知。应用启动兼容旧库 task_id 扩展。对已有数据库应先备份并核对结构。
