# Custos

加密工作台保存账号密码、AI API Key 和 MT5 账户；提供搜索、待办、日历、设置、加密备份和导入。首次设置主密码后生成 24 词助记词并完成留存验证；支持主密码解锁及助记词找回。主密码通过 PBKDF2-SHA256 派生密钥，随机数据密钥采用 AES-GCM 包裹并加密库内容；SQLite 只保存密钥包装信息和密文。多设备通过同一应用同步，版本冲突时拒绝覆盖并提示刷新。

界面使用侧栏导航、顶部搜索及锁定和主题控件；首页显示待办、最近编辑、分类统计和月历。保留浅色与深色皮肤、窄屏布局和卡片详情编辑流程。新应用为空库，用户可导入加密备份。加密和解密在浏览器执行。
