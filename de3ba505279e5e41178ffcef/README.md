# 单词听写小帮手

选择单元或单词后设置顺序、语言、重复次数及间隔，开始听写；也可生成和下载听写音频。设备需支持浏览器语音合成。选择和播放状态只保留在当前页面，无数据库。

安装源码后填写 source.json 的 Git 实例 ID，执行 `npm ci` 和 `npm run build -- <完整源码提交号>`，发布 dist。安装器会将语音和字体写入应用的文件目录；生成音频时按需读取分段，无法读取时会显示错误。

语音素材可以通过 `scripts/build-audio-sprites.py` 从完整的原始 MP3 目录重新生成；需要 Python、NumPy 和 FFmpeg。脚本参数依次为原音频目录、输出目录和摘要记录文件。生成过程保留 MP3 音频帧并校验每段解码后的采样对齐。
