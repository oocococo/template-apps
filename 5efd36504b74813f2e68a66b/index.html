正则语法速查表
写法含义
.任意字符（默认不含换行，加 s 后含）
[abc]字符集合：a、b 或 c
[^abc]除 a、b、c 之外的字符
\d \D数字 [0-9] / 非数字
\w \W单词字符 [A-Za-z0-9_] / 非单词字符
\s \S空白字符（空格、制表、换行）/ 非空白
写法含义
^ $字符串开头 / 结尾（m 模式下为每行）
\b \B单词边界 / 非单词边界
写法含义
* + ?重复 0 次或多次 / 1 次或多次 / 0 或 1 次
{n} {n,} {n,m}恰好 n 次 / 至少 n 次 / n 到 m 次
*? +? ??懒惰匹配：尽可能少地重复
写法含义
(abc)捕获分组，可用 \1 或 $1 引用
(?:abc)非捕获分组，只分组不捕获
(?<name>abc)命名分组
a|b选择：匹配 a 或 b
g i m s u y全局 / 忽略大小写 / 多行 / 点匹配换行 / Unicode / 粘性
使用说明与常见问题

三步上手：

  1. 在「正则」框输入或粘贴正则表达式，默认开启 g（全局匹配），可点「标志位」组合 i / m / s / u / y。
  2. 在「测试文本」框粘贴要校验的内容，输入停止约 0.15 秒后自动出结果。
  3. 左侧查看高亮预览，右侧查看匹配数量、耗时与每条匹配的区间；点击匹配条目可展开捕获分组（含命名分组）。

小技巧：不确定怎么写？点上方「预设」可一键填入邮箱、手机号、URL、IPv4、日期等常用正则及配套示例文本。

常见问题：

  • 出现红色报错条：说明正则语法有误（如括号没有配对），按提示修改即可，已输入的内容不会丢失。
  • 没有匹配：检查是否开启了 i（忽略大小写）；部分标志位会改变匹配行为。
  • 「空匹配」：正则匹配了空字符串（例如 a* 在没有任何 a 的位置），这是正常现象。
  • 文本特别大时（超过 10 万字符）只做统计不做高亮，避免页面卡顿。

所有匹配计算都在你的浏览器本地完成，文本不会上传、不会被保存，关掉页面即消失。
