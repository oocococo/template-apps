# 蹬王之王

维护额度、重置卡和积分 JSON 台账，按最先到期原则展示建议与理由。用户自行维护数据；应用不读取账户，不自动用卡。打开页面可定时重算，关闭后不巡检。

同一安装的获授权使用者共享一个台账和配置；不同安装的数据独立。保存使用版本比较，若多人同时修改，后保存者遇到冲突应重新载入并合并，避免覆盖。

台账编辑器位于页面底部；支持保存、重新载入、错误反馈。缺失 credits 代表数据不完整，空数组才表示没有积分。坏 JSON、无效数组类型、读取和保存错误均明确提示。未保存内容不当成已保存。

额度按已用比例计算，默认触发 99%，紧张 80%、不足 95%，刷新前 60 分钟避免消耗卡；配置可修改并验证。有效卡需 sourceType、outBizNo 且未过期；积分须余额正且到期时间在未来。未触发先等待；触发且积分数据不完整时等待；无积分有卡则建议用卡，无卡有积分则建议用积分，两者都有时比较最早到期，相同时间选积分；需要用卡且已进入刷新窗口时等待。完整理由随结论显示。

界面为白底卡片布局，页面依次显示预警、四项概览、建议、页面自动重算、阈值、积分和卡到期、过期损失、折叠 JSON 编辑器。使用系统字体、浅边框、12px 圆角、蓝绿橙红状态色；窄屏双栏变单栏，表格可横向滚动。开关及按钮采用短过渡。
