# 学生电脑使用管理软件

手动记录使用时间、管理应用和学习任务、运行番茄钟、查看报告及页面内健康提醒。数据保存在当前浏览器；时长与时段设置不读取或控制其他应用，不锁定设备或向家长发送通知。关闭页面后计时与提醒不会运行。管理密码只用于本地界面的操作提示，不提供安全防护。可导出、导入 JSON 备份。

使用 `tiana web init-template wb1024-c224-0dec6bf6 --dir <目录>` 获取源码，将 `source.json` 的 Git 实例占位符替换为真实实例 ID，然后执行 `npm ci` 和 `npm run build -- <完整提交号>`。无需数据库。
